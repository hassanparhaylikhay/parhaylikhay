You've now seen all the core rate types Cambridge tests: pay, exchange, flow, fuel, speed, density, pressure, population density. Every problem follows the same pattern: identify the rate, decide whether to multiply or divide, include units.

## The skills you should have

- **Recognise rates** from their units (\$/h, km/l, m/s, g/cm³, etc.).
- **Apply $D = S \times T$** and rearrange for any of the three.
- **Convert mixed-unit times** ($45$ min $= 0.75$ h) before using a formula.
- **Convert speed units** between km/h and m/s using the $\tfrac{5}{18}$ factor.
- **Use given formulae** for density, pressure, population density.
- **Always include units** in the final answer.

## Marking patterns

| Question style | Marks | Notes |

| "Convert $X$ km/h to m/s" | 1–2 | M1 for the $\tfrac{5}{18}$ factor or division by $3.6$, A1 for the value |
| "Find density" (formula given) | 2 | M1 for substituting into $\rho = m/V$, A1 for the value with units |
| "Hourly pay × hours" | 1 | B1 for the answer with currency |

## The single biggest mistake

**Treating $h$ min as $h.\text{min}$.** $3$ h $45$ min is $3.75$ hours, not $3.45$. Convert minutes to a decimal fraction of an hour ($\tfrac{45}{60}$) before any speed calculation.
