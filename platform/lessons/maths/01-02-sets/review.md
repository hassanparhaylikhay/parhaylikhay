## The skills you should have

- **Read and write set notation**: $\in$, $\notin$, $n(A)$, $\emptyset$, $\xi$, $\subseteq$, $\nsubseteq$, $\cup$, $\cap$, complement $A'$.
- **Translate between roster and set-builder forms.**
- **Find $A \cup B$, $A \cap B$, $A'$** for given sets in a universal set.
- **Shade the region** on a 2-set or 3-set Venn diagram for any combination of $\cup$, $\cap$, and complement.
- **Solve numerical Venn problems** using the "intersection first" strategy.

## Marking patterns

Cambridge Sets questions usually break down into three styles, each with its own typical mark allocation:

| Question style | Marks | What gets the marks |
|---|---|---|
| List elements of a set from set-builder | 1 | The full correct list |
| Compute a combined set ($A \cap B'$ etc.) | 1–2 | Method (correct breakdown) + answer |
| Shade a region on a Venn | 1–2 | Correct region identified + clean shading |
| Numerical Venn word problem | 3–4 | M1 method (intersection first), B1 each region, A1 final |

Three universal markers to keep in mind:

- **B1** for stating $n(\text{something})$ correctly.
- **M1** for the method, usually "fill the centre first, then subtract".
- **A1** for the final answer to the question being asked.

## The single biggest mistake

Across every Sets question, the most common error is **double-counting the overlap**. Whenever a problem says "$X$ study A and $Y$ study B, $Z$ study both", remember that the $Z$ is *already* inside the $X$ and the $Y$. Subtract it out before reading off the regions.

If that one habit becomes automatic, you'll get the marks on every Sets question Cambridge sets.
