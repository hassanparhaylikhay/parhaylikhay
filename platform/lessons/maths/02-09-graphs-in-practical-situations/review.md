## What you should know by now

If you've worked through P1 to P3 you can:

- Read distance-time graphs: gradient = speed; horizontal = stationary; downward = returning.
- Read speed-time graphs: gradient = acceleration; area = distance.
- Compute distances under v-t graphs as rectangles, triangles, or trapeziums.
- Use conversion graphs by reading off, or by computing from the line's gradient.
- Recognise common graph shapes (linear vs parabolic) for typical practical scenarios.

## Marking patterns at a glance

This sub-topic is heavily Paper 2:

- **B1** for "what does the gradient (or area) represent".
- **M1 + A1** for "find the speed in this segment" or "find the acceleration".
- **M1 + A1** for "find the total distance" using the area under v-t.
- **M1, M1, A1** for multi-stage v-t problems (compute each piece, sum).

The trap markers Cambridge uses repeatedly:

- Confusing d-t and v-t. On d-t, gradient = speed. On v-t, gradient = acceleration; area = distance.
- "Horizontal line" interpretation: stationary on d-t, constant speed on v-t.
- Forgetting units in the answer.
- Using the wrong area formula: trapezium for a stage with constant non-zero acceleration that doesn't start at zero.

## Worked example: a multi-stage v-t problem

A train accelerates from rest for $20$ s reaching $30$ m/s. It then travels at constant $30$ m/s for $1$ minute. Finally, it decelerates uniformly to rest in $10$ s.

(a) Find the acceleration in the first stage.

(b) Find the total distance travelled.

**Step 1 (a).**

$$a_1 = \dfrac{30 - 0}{20} = 1.5 \text{ m/s}^2$$

**Step 2 (b): The whole shape is a trapezium.**

- Top side (constant-speed segment): $60$ s.
- Bottom side (total time): $20 + 60 + 10 = 90$ s.
- Height (max speed): $30$ m/s.

$$\text{distance} = \dfrac{1}{2} (60 + 90) (30) = \dfrac{1}{2} (150)(30) = 2250 \text{ m}$$

**Answer:** **(a)** $1.5$ m/s². **(b)** $2250$ m. **[M1 for stage 1; M1 for trapezium area; A1 for the value]**

Full marks $= 3$.

## Quick reference

- **Distance-time**: gradient = speed.
- **Speed-time**: gradient = acceleration; area = distance.
- **Conversion graph**: gradient = conversion rate.
- For curves, use the **tangent** at a point for the instantaneous rate.
- Match the shape: rectangle for constant value, triangle for "0 to N", trapezium for "$M$ to $N$".
