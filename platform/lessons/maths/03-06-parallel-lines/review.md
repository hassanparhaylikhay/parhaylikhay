## What you should know by now

If you've worked through P1 you can:

- State that two lines are parallel iff they have the **same gradient** (and different y-intercepts).
- Convert any line equation to $y = mx + c$ form and read off $m$ to test for parallelism.
- Find the equation of the line parallel to a given line passing through a given point.

## Marking patterns at a glance

For "find the parallel line through point":

- **B1** for stating the gradient (copying it from the given line).
- **M1** for substituting the point into $y = mx + c$.
- **A1** for the final equation.

## Worked example

A line $L_1$ has equation $2y = 6x - 5$.

(a) Find the gradient of $L_1$.

(b) Find the equation of the line $L_2$ parallel to $L_1$ that passes through the point $(3, 1)$.

**Step 1 (a, rearrange).** Divide both sides by $2$:

$$y = 3x - \dfrac{5}{2}$$

**Step 2 (a, gradient).** Read off: gradient of $L_1$ is $3$.

**Step 3 (b, gradient of $L_2$).** Parallel → same gradient. So gradient of $L_2$ is $3$.

**Step 4 (b, substitute point).**

$$1 = 3(3) + c$$

**Step 5 (b, solve).**

$$1 = 9 + c \;\Rightarrow\; c = -8$$

**Answer (a):** Gradient of $L_1$ is $3$. **[B1]**

**Answer (b):** $L_2: y = 3x - 8$. **[B1 gradient; M1 substitute; A1 final]**

Full marks $= 4$.

## Quick reference

- Parallel ⟺ same $m$.
- Recipe: keep $m$, find new $c$ from the given point.
