## Why this matters

Grouped data is given as a frequency table with CLASSES (intervals) instead of individual values. The exam asks two flavours of question:

1. **Estimated mean from grouped data**, a $3$- to $4$-mark calculation.
2. **Modal class**, a $1$-mark identification.

Both come up frequently. The mean formula is short but error-prone, so a clean working layout helps a lot.

## The estimated mean formula

Each class has:

- A **lower bound** and an **upper bound** defining the interval.
- A **midpoint** $x$, the average of the bounds.
- A **frequency** $f$, the number of values in that class.

The estimated mean treats every value in a class as equal to the class midpoint. Then it''s a weighted mean:

$$\boxed{\text{estimated mean} = \dfrac{\sum f \cdot x}{\sum f}}$$

Where $\sum f \cdot x$ means "for each row, multiply midpoint by frequency, then add up". And $\sum f$ is the total frequency (sample size).

## Modal class

The **modal class** is the class with the HIGHEST frequency. That is the entire skill for that question.

In the table above, the modal class is a tie between $20$-$30$ and $30$-$40$ (both frequency $11$). Some questions are written to avoid ties; if you get a tie, write both classes.

The modal class is NOT a specific number. It is a CLASS (an interval). Your exam wants you to write the interval, e.g. $20 \leq x < 30$, not a midpoint.

A frequency table of test scores for $40$ students:

- $0$-$10$ (mid $5$): $f = 2$
- $10$-$20$ (mid $15$): $f = 6$
- $20$-$30$ (mid $25$): $f = 11$
- $30$-$40$ (mid $35$): $f = 14$
- $40$-$50$ (mid $45$): $f = 7$

**Step 1: Compute $f \cdot x$ for each row.**

- $5 \times 2 = 10$
- $15 \times 6 = 90$
- $25 \times 11 = 275$
- $35 \times 14 = 490$
- $45 \times 7 = 315$

**Step 2: Totals.**

$\sum f \cdot x = 10 + 90 + 275 + 490 + 315 = 1180$

$\sum f = 2 + 6 + 11 + 14 + 7 = 40$

**Step 3: Divide.**

$$\text{estimated mean} = \dfrac{1180}{40} = 29.5$$

**Answer:** Estimated mean $= \boxed{29.5}$. **[M1 for $\sum f \cdot x$; M1 for dividing by $\sum f$; A1 for $29.5$]**

Full marks $= 3$.

## Common mistakes

- **Using class bounds instead of midpoints.** The MIDPOINT is the representative value, not the lower or upper bound.
- **Dividing by the number of classes** instead of $\sum f$. The denominator is the TOTAL FREQUENCY (the sample size).
- **Forgetting one row** in the sum.
- **Writing "modal class = 11"**. Modal CLASS is the interval, not the frequency.
- **Calling the estimated mean exact**. It is always an estimate because we used midpoints.

## Quick summary

- **Estimated mean** $= \dfrac{\sum f \cdot x}{\sum f}$ where $x$ is the midpoint.
- **Modal class** = highest-frequency class. Write it as an interval.
- The 3-column layout (midpoint, frequency, product) catches arithmetic errors.
- Always called an ESTIMATED mean because each value is replaced by its class midpoint.
