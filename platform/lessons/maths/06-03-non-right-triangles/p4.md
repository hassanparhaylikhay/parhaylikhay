## What the cosine rule says

For any triangle, the cosine rule links one side to the other two sides and the angle **between** them:

$$a^{2} = b^{2} + c^{2} - 2bc\cos A$$

If $A = 90°$, $\cos A = 0$ and the formula collapses to $a^{2} = b^{2} + c^{2}$, which is just Pythagoras. So the cosine rule **generalises Pythagoras** to any triangle. The extra $-2bc\cos A$ term corrects for the angle not being right.

## When to use it

Two situations where the cosine rule is the right tool:

The keyword is **"included"**. If the known angle is wedged BETWEEN the two known sides, cosine rule. If the known angle is OPPOSITE one of the sides instead, sine rule (and the previous part's ambiguous-case rules apply).

## Worked example: find a side (SAS)

A triangle has $b = 7$, $c = 8$, and the included angle $\angle A = 50°$. Find side $a$.

<iframe src="/widgets/trig-non-right-step-explorer.html?preset=cosine-rule-find-side" style="width:100%;max-width:696px;height:540px;border:0;border-radius:10px;display:block;margin:18px auto" loading="lazy"></iframe>

Plug straight in:

$$a^{2} = 7^{2} + 8^{2} - 2(7)(8)\cos 50°$$

$$a^{2} = 49 + 64 - 112\cos 50° \approx 113 - 71.99 = 41.01$$

$$a = \sqrt{41.01} \approx 6.40\;\text{cm}$$

**[M1 for $a^{2} = 7^{2}+8^{2}-2(7)(8)\cos 50°$; A1 for $a = 6.40$]**

Full marks $= 2$.

## Worked example: find an angle (SSS)

A triangle has sides $a = 8$, $b = 5$, $c = 7$. Find the angle opposite the longest side (i.e. find $\angle A$).

<iframe src="/widgets/trig-non-right-step-explorer.html?preset=cosine-rule-find-angle" style="width:100%;max-width:696px;height:540px;border:0;border-radius:10px;display:block;margin:18px auto" loading="lazy"></iframe>

Rearrange the cosine rule to isolate $\cos A$:

$$\cos A = \dfrac{b^{2} + c^{2} - a^{2}}{2bc}$$

$$\cos A = \dfrac{25 + 49 - 64}{2(5)(7)} = \dfrac{10}{70} \approx 0.1429$$

$$A = \cos^{-1}(0.1429) \approx 81.8°$$

**[M1 for $\cos A = (b^{2}+c^{2}-a^{2})/(2bc)$; M1 for $\cos A = 10/70$; A1 for $A = 81.8°$]**

Full marks $= 3$.

## The rearranged form

For SSS problems it's faster to write the cosine rule already rearranged:

$$\cos A = \dfrac{b^{2} + c^{2} - a^{2}}{2bc}$$

This is **not** on the formula sheet (only the standard form is). You derive it by moving $2bc\cos A$ to the left and dividing both sides by $2bc$. Doing it once on rough working at the start of a paper saves time when SSS questions come up.

## Why the obtuse case is easy here

Unlike the sine rule, the cosine rule has **no ambiguity**. The function $\cos$ is one-to-one over $0°$ to $180°$ (it strictly decreases). So $\cos^{-1}$ always returns a single, correct value, even if the angle is obtuse.

- If $\cos A > 0$: $A$ is acute.
- If $\cos A = 0$: $A = 90°$ exactly (Pythagoras case).
- If $\cos A < 0$: $A$ is obtuse, and $\cos^{-1}$ returns the correct obtuse value automatically.

This is why the cosine rule is often the safer first reach for SSS problems when one of the angles might be obtuse.

## Common mistakes

- **Plugging the wrong side as $a$.** $a$ must be the side OPPOSITE the angle in the formula. If you want $\angle A$, $a$ is its opposite side.
- **Sign error on the $-2bc\cos A$ term.** Some students copy it as $+2bc\cos A$. Triple-check the sign on the formula sheet.
- **Forgetting to square root for SAS.** The cosine rule gives $a^{2}$, not $a$. Final step is $\sqrt{\;\;}$.
- **Mixing rules.** SSS / SAS → cosine rule. Two angles + a side → sine rule. Quick sanity check before substituting.
- **Premature rounding.** Keep $\cos 50°$ to full precision on the calculator. Don't round to $0.64$ midway.

## Quick summary

- Cosine rule: $a^{2} = b^{2} + c^{2} - 2bc\cos A$. Formula sheet.
- Generalises Pythagoras (which is the $A = 90°$ case).
- Use it for **SAS** (two sides + included angle, find third side) or **SSS** (three sides, find any angle).
- Rearranged for angles: $\cos A = \dfrac{b^{2} + c^{2} - a^{2}}{2bc}$.
- No ambiguity: $\cos^{-1}$ returns the correct value directly, acute or obtuse.
