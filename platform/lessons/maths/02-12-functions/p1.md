## Why this matters

Up until now you've written things like $y = 3x + 5$ and $y = x^2$. Functions take that one step further: a name, an input variable, and a rule. Cambridge introduces this notation in 2.12 because it's the language used for **inverse functions** (next part) and **composite functions** (the part after).

Once you can write $f(x) = 3x + 5$ and evaluate $f(4)$ confidently, the rest of unit 2.12 is plug-and-chug.

## Function notation

A function is written as

$$f(x) = \text{(some expression in } x\text{)}$$

You read this as "f of x equals ...". Think of $f$ as a **machine**: you put $x$ in, the machine applies the rule, and a value comes out.

To evaluate the function at a specific input, replace every $x$ in the rule with that input.

**Example.** If $f(x) = 3x - 5$, then

- $f(4) = 3(4) - 5 = 7$
- $f(0) = 3(0) - 5 = -5$
- $f(-2) = 3(-2) - 5 = -11$

The output $7$ is sometimes written as the **image** of $4$ under $f$, in mapping notation:

$$f: 4 \mapsto 7$$

The arrow $\mapsto$ ("maps to") emphasises that $f$ is a process turning an input into an output. Different functions can have different names ($g$, $h$, etc.) and different inputs.

## Domain: what's allowed in

The **domain** is the set of input values $x$ for which $f(x)$ is defined. For most functions you'll meet, the domain is "all real numbers" — but watch for these exceptions:

| Function form | Domain restriction | Why |
|---|---|---|
| $f(x) = \dfrac{1}{x - a}$ | $x \neq a$ | Cannot divide by zero |
| $f(x) = \sqrt{x - a}$ | $x \geq a$ | Cannot take real square root of a negative |
| $f(x) = \dfrac{1}{\sqrt{x - a}}$ | $x > a$ | Both restrictions: positive and non-zero |

**Example.** $f(x) = \dfrac{1}{x + 3}$ has domain $x \neq -3$.

**Example.** $f(x) = \sqrt{2x - 6}$ has domain $2x - 6 \geq 0$, i.e. $x \geq 3$.

## Range: what comes out

The **range** is the set of all output values $f(x)$ takes as $x$ varies over the domain. Some common ranges:

- $f(x) = 3x - 5$, domain all real $x$: range all real $y$ (a line is unbounded).
- $f(x) = x^2$, domain all real $x$: range $y \geq 0$ (squares are non-negative).
- $f(x) = \sqrt{x}$, domain $x \geq 0$: range $y \geq 0$.
- $f(x) = \dfrac{1}{x}$, domain $x \neq 0$: range $y \neq 0$.

The easy way to find the range: think about the **graph** of $f$. The range is the set of $y$-values the graph reaches.

## Worked example

Let $f(x) = 3 - 2x$ and $g(x) = x^2 + 1$.

(a) Find $f(5)$.

(b) Find $g(-3)$.

(c) Solve $f(x) = -7$ for $x$.

(d) State the range of $g$ for domain all real $x$.

**Step 1 (a).** $f(5) = 3 - 2(5) = 3 - 10 = -7$.

**Step 2 (b).** $g(-3) = (-3)^2 + 1 = 9 + 1 = 10$.

**Step 3 (c).** Set $3 - 2x = -7$ → $-2x = -10$ → $x = 5$.

**Step 4 (d).** $x^2 \geq 0$ for all real $x$, so $g(x) = x^2 + 1 \geq 1$. Range: $y \geq 1$.

**Answer:** **(a)** $f(5) = -7$. **(b)** $g(-3) = 10$. **(c)** $x = 5$. **(d)** Range is $y \geq 1$. **[B1 each]**

Full marks $= 4$.

## Common mistakes

- Squaring before applying the negative: $(-3)^2 = 9$, not $-9$. Brackets matter.
- Calling the input $x$ "the function". $x$ is the input; $f$ is the function (the rule).
- Confusing domain and range. Domain = inputs, range = outputs. (Mnemonic: D before R; input before output.)
- Forgetting to check for division-by-zero or negative-under-square-root when stating a domain.

## Quick summary

- $f(x) = $ rule means "apply this rule to the input $x$".
- $f(a)$ means "substitute $a$ for $x$ everywhere in the rule".
- Domain = allowed inputs. Range = resulting outputs.
- Domain restrictions come from $\dfrac{1}{0}$ (forbidden), $\sqrt{\text{negative}}$ (forbidden).
