## Why this matters

A composite function is what you get when you feed the output of one function into another: do $f$ first, take the result, feed it into $g$. The combined operation is a new function, written $gf$ (or sometimes $g \circ f$).

This is the natural language for "do this, then do that". Cambridge uses it to test whether you can read the notation correctly (reading order is the trap) and substitute carefully.

## The notation $gf(x)$

$$gf(x) = g(f(x))$$

The function on the **right** ($f$) is applied **first**. The function on the **left** ($g$) is applied **second**.

A useful way to remember: read the symbols closest-to-$x$ outward. $gf(x)$: $f$ is next to $x$, so $f$ goes first.

**Reading order matters.** $gf(x)$ and $fg(x)$ are usually NOT equal. We'll see an example below.

## Computing a composite

To find $gf(x)$:

1. Compute $f(x)$ (just write the rule).
2. Substitute that whole expression in place of $x$ in $g$'s rule.
3. Simplify.

### Example 1

$f(x) = x + 3$ and $g(x) = 2x$. Find $gf(x)$ and $fg(x)$.

**$gf(x)$:**

$$gf(x) = g(f(x)) = g(x + 3) = 2(x + 3) = 2x + 6$$

**$fg(x)$:**

$$fg(x) = f(g(x)) = f(2x) = 2x + 3$$

These are different. $gf(x) = 2x + 6$, but $fg(x) = 2x + 3$.

### Example 2

$f(x) = 3x + 1$ and $g(x) = x^2$. Find $gf(x)$.

$$gf(x) = g(f(x)) = g(3x + 1) = (3x + 1)^2$$

You can leave it as $(3x + 1)^2$ or expand to $9x^2 + 6x + 1$ — Cambridge accepts either, but the simplified form scores.

### Example 3: composing with itself

$f(x) = 3x + 1$. Find $ff(x)$.

$$ff(x) = f(f(x)) = f(3x + 1) = 3(3x + 1) + 1 = 9x + 3 + 1 = 9x + 4$$

So if $f$ "multiplies by 3 and adds 1", then $ff$ "multiplies by 9 and adds 4".

## Worked example

$f(x) = \dfrac{3}{x + 2}$ and $g(x) = (3x + 5)^2$.

(a) Find $fg(x)$, simplifying to a fraction.

(b) Find $f(g(0))$.

**Step 1 (a).**

$$fg(x) = f(g(x)) = f((3x + 5)^2) = \dfrac{3}{(3x + 5)^2 + 2}$$

**Step 2 (b).**

$$g(0) = (3(0) + 5)^2 = 25$$

$$f(g(0)) = f(25) = \dfrac{3}{25 + 2} = \dfrac{3}{27} = \dfrac{1}{9}$$

**Answer:** **(a)** $fg(x) = \dfrac{3}{(3x + 5)^2 + 2}$. **(b)** $f(g(0)) = \dfrac{1}{9}$. **[M1 substitute g into f; A1 simplify; M1 evaluate g(0); A1 final]**

Full marks $= 4$.

## Order matters: $gf \neq fg$ in general

The single biggest student mistake here is reading $gf(x)$ as "apply $g$ then $f$". WRONG. The function NEXT to $x$ is applied first.

Mnemonic: in $gf(x)$, the $x$ "sees" $f$ first (it's right next to it). $f$ acts; the result is then handed to $g$.

If you ever feel uncertain, write it out as $g(f(x))$ explicitly.

## Common mistakes

- Reading $gf(x)$ in left-to-right order. The function next to $x$ goes FIRST.
- Forgetting brackets when substituting. $g(f(x)) = g(x + 3)$ → if $g$ is "double", that's $2(x + 3)$, NOT $2x + 3$. The whole expression $x + 3$ is the input, so it gets multiplied by 2.
- Trying to compose functions where the inner function's output isn't in the outer's domain. Cambridge asks you not to worry about composite domains in O-Level (per syllabus) — just compute the algebra.
- Mixing up $f^{-1}$ and $ff^{-1}$. They're related but different: $f^{-1}$ is the inverse function (its own object); $ff^{-1}(x)$ is the composition that reduces to $x$.

## Quick summary

- $gf(x) = g(f(x))$: apply $f$ first (it's closest to $x$), then $g$.
- $gf$ and $fg$ are usually different functions.
- Process: compute $f(x)$, plug result into $g$'s rule, simplify.
- $ff^{-1}(x) = x$ (composition with the inverse cancels).
