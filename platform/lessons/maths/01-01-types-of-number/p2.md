## What this part is about

Numbers come in **families**. Each family sits inside a bigger one, like Russian dolls. Before you can decide whether $\sqrt{8}$ is rational or irrational, you need to know what those words mean, which is what this part is for.

## The four families

**Natural numbers**, the counting numbers: $1, 2, 3, 4, \ldots$. *(Some books include 0. Cambridge 4024 starts from 1.)* Symbol: $\mathbb{N}$.

**Integers**, the naturals, zero, and the negatives: $\ldots, -3, -2, -1, 0, 1, 2, 3, \ldots$. Every integer is a **whole number** *(no decimal or fraction part)*. Symbol: $\mathbb{Z}$.

**Rational numbers**, any number you can write as a fraction $\dfrac{p}{q}$ where $p$ and $q$ are both integers and $q \neq 0$. Symbol: $\mathbb{Q}$. Examples: $\dfrac{3}{4}$, $-\dfrac{7}{2}$, $5$ (because $5 = \dfrac{5}{1}$).

**Real numbers**, every number you can plot on a number line. That includes all the rationals, *and* numbers like $\pi$ and $\sqrt{2}$ that can't be written as fractions. Symbol: $\mathbb{R}$.

## How they nest

Each family sits inside the next:

$$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$$

Read that as: **naturals inside integers inside rationals inside reals**. The symbol $\subset$ means "is a subset of", every member of the smaller set is also a member of the bigger one.

The diagram above shows how this works. The **irrationals** *(numbers that can't be written as a fraction)* sit inside the reals $\mathbb{R}$ but **outside** the rationals $\mathbb{Q}$. That's the only place in this system where something is "outside" something else.

## Why this matters for classification questions

A Cambridge exam question might give you a list and ask "which of these is irrational?" or "which is an integer?" To answer quickly, run each number through a mental check:

1. Is it a whole number (no decimal, no fraction)? If yes → it's at least an integer.
2. Is it positive and ≥ 1? If also yes → it's natural.
3. Can it be written as a fraction of integers? If yes → it's rational.
4. If it can't be written as a fraction → it's irrational.
5. Everything that ends up on the number line is real.

A number can carry **multiple labels at once**. $7$ is natural *and* integer *and* rational *and* real. But every number has one "innermost" family, the smallest set it belongs to. For $7$, that's natural.

## Worked example

From the list $\{-3,\ 0,\ 4,\ \tfrac{1}{2},\ \pi\}$, identify:

(a) the natural numbers,
(b) the integers that are **not** natural numbers,
(c) the rational number that is not an integer.

**Working.**

(a) Naturals are the counting numbers $\{1, 2, 3, \ldots\}$. From the list, only $\boxed{4}$. **[B1]**

(b) Integers not natural means whole numbers that aren't in $\{1, 2, 3, \ldots\}$. $-3$ and $0$ qualify. Answer: $\boxed{-3,\ 0}$. **[B1]**

(c) Rational non-integer means a fraction that doesn't simplify to a whole number. $\tfrac{1}{2} = 0.5$, rational but not whole. Answer: $\boxed{\tfrac{1}{2}}$. **[B1]**

Full marks $= 3$.

> **Examiner tip:** When a list contains a square root, work it out before classifying. $\sqrt{4}$ is just $2$, a natural number, not a mysterious "root" that needs special treatment. We will see exactly this trap in Part 3.
