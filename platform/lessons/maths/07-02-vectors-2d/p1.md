## Meet a vector

<iframe src="/widgets/vector-intro-explorer.html" style="width:100%;max-width:696px;height:560px;border:0;border-radius:10px;display:block;margin:6px auto 18px" loading="lazy"></iframe>

The yellow arrow above is a **vector**. It has two facts about it: how LONG it is (the size, or **magnitude**) and which way it POINTS (the direction). The little column underneath, $\begin{pmatrix} 4 \\ 3 \end{pmatrix}$, is just a tidy way to capture both: top number says how far right, bottom number says how far up.

Drag $A$ or $B$ around. Notice how the column changes the moment the arrow does, and stays exactly equal to $B - A$. Try sliding $A$ and $B$ both by the same amount in the same direction. The arrow looks identical, just shifted; the column does not change. **A vector does not care where you draw it.** Only the length and direction matter.

## Why this matters

Throw a cricket ball $20\,\text{metres}$. That tells me how far, but not where. To describe the throw completely, you also need the direction: $20\,\text{metres}$ towards the boundary, or $20\,\text{metres}$ straight up. Anything you can describe with one number (just a size) is a **scalar**. Anything that also needs a direction is a **vector**.

## Three ways to write a vector

The same arrow has three common notations. All three mean the same thing.

## Finding $\vec{AB}$ from coordinates

Given two points $A$ and $B$ on a grid, the vector between them is "end minus start":

$$\vec{AB} = B - A = \begin{pmatrix} x_B - x_A \\ y_B - y_A \end{pmatrix}$$

Top of the column is the change in $x$ from $A$ to $B$; bottom is the change in $y$. This is the same trick as image minus object from translations in 7.1.

## The reverse vector: $\vec{BA} = -\vec{AB}$

If $\vec{AB}$ takes you from $A$ to $B$, then $\vec{BA}$ takes you the other way, from $B$ back to $A$. Same length, opposite direction. The column flips both signs:

$$\vec{AB} = \begin{pmatrix} a \\ b \end{pmatrix} \quad\Rightarrow\quad \vec{BA} = \begin{pmatrix} -a \\ -b \end{pmatrix} = -\vec{AB}$$

Quick check: $\vec{AB} + \vec{BA}$ should equal $\begin{pmatrix} 0 \\ 0 \end{pmatrix}$, the **zero vector**. You went from $A$ to $B$ and straight back to $A$, so you have moved nowhere.

## Worked example: find the column vector from two points

Point $A$ is at $(2, 1)$. Point $B$ is at $(5, 5)$. Write $\vec{AB}$ as a column vector.

<iframe src="/widgets/transformations-step-explorer.html?preset=7p2-p1-find-vector" style="width:100%;max-width:696px;height:620px;border:0;border-radius:10px;display:block;margin:18px auto" loading="lazy"></iframe>

**Step 1: Set up $B - A$.** $\vec{AB}$ always equals the end point minus the start point.

**Step 2: Subtract component by component.**

$$\vec{AB} = \begin{pmatrix} 5 - 2 \\ 5 - 1 \end{pmatrix}$$

**Answer:** $\boxed{\vec{AB} = \begin{pmatrix} 3 \\ 4 \end{pmatrix}}$. **[M1 for setting up $B - A$; A1 for the correct column]**

Full marks $= 2$.

## Common mistakes

- **Writing $A - B$ instead of $B - A$.** The vector $\vec{AB}$ starts at $A$ and ENDS at $B$. To get there, subtract the start FROM the end. End minus start.
- **Writing the vector in row form**: $(3, 4)$. A row is for a coordinate, not a vector. Vectors are always columns.
- **Forgetting the arrow on $\vec{AB}$.** Without the arrow it looks like the product of two letters. The arrow tells the reader "this is a vector, from $A$ to $B$".
- **Not underlining the bold letter when handwriting**. $\mathbf{a}$ is bold in print, but you cannot bold pen ink. Underline: $\underline{a}$.
- **Thinking two vectors are different just because they start at different points.** Two parallel arrows of the same length anywhere on the grid are the same vector.

## Quick summary

- A vector has size AND direction. A column vector $\begin{pmatrix} a \\ b \end{pmatrix}$ captures both.
- Three notations for the same vector: $\vec{AB}$, $\mathbf{a}$ (or $\underline{a}$ handwritten), and the column form.
- $\vec{AB} = B - A$: end minus start.
- $\vec{BA} = -\vec{AB}$: the reverse vector flips both signs.
- A vector is fixed by its components alone; the starting point does not matter.
