## Why this matters

Fractional indices are how Cambridge writes roots. $\sqrt{6}$ and $6^{1/2}$ are the same number; the index notation is just shorter, and it lets the rules of indices work on roots too. Once you can convert $a^{m/n}$ into "take the $n$th root, raise to the $m$th power", every Paper 1 fractional-index question is mechanical.

## The rule for $1/n$

A fractional index of the form $\textcolor{#00abfa}{1/n}$ means take the $n$th **<span style="color:#0fee89">root</span>**:

$$\textcolor{#fff067}{a}^{\textcolor{#00abfa}{1/n}} \;=\; \sqrt[\textcolor{#00abfa}{n}]{\textcolor{#fff067}{a}}$$

So:

- $a^{1/2} = \sqrt{a}$ (square root)
- $a^{1/3} = \sqrt[3]{a}$ (cube root)
- $a^{1/4} = \sqrt[4]{a}$ (fourth root)
- $a^{1/n} = \sqrt[n]{a}$ in general

Why this works: by Rule 3 from p1, $(a^{1/n})^n = a^{(1/n) \times n} = a^1 = a$. So $a^{1/n}$ is exactly the number that gives $a$ when raised to the $n$th power, which is the definition of the $n$th root.

## The rule for $m/n$

When the index is a fraction $\textcolor{#00abfa}{m/n}$, the **denominator** $\textcolor{#00abfa}{n}$ tells you which **<span style="color:#0fee89">root</span>** to take and the **numerator** $\textcolor{#00abfa}{m}$ tells you which **power** to raise to:

$$\textcolor{#fff067}{a}^{\textcolor{#00abfa}{m/n}} \;=\; \left(\sqrt[\textcolor{#00abfa}{n}]{\textcolor{#fff067}{a}}\right)^{\textcolor{#00abfa}{m}} \;=\; \sqrt[\textcolor{#00abfa}{n}]{\textcolor{#fff067}{a}^{\textcolor{#00abfa}{m}}}$$

Both orderings give the same answer, but **rooting first keeps the numbers small**. Always take the root first.

## Combining with negative indices

Fractional and negative indices stack: a negative fractional index reciprocates AND takes a root. Compute the magnitude using the fraction rule, then put the result in the denominator:

$$\textcolor{#fff067}{a}^{-\textcolor{#00abfa}{m/n}} \;=\; \dfrac{1}{\textcolor{#fff067}{a}^{\textcolor{#00abfa}{m/n}}}$$

**Example.** $25^{-1/2} = \tfrac{1}{25^{1/2}} = \tfrac{1}{\sqrt{25}} = \tfrac{1}{5}$.

**Example.** $8^{-2/3} = \tfrac{1}{8^{2/3}} = \tfrac{1}{4}$.

<div class="trap-callout">

**Trap: in $a^{m/n}$, the denominator is the root, not the power.** $8^{2/3}$ means cube root then square, NOT square then cube root (those are the same here, but only because both are valid). $32^{3/5}$ means fifth root then cube: $\sqrt[5]{32} = 2$, then $2^3 = 8$. If you mix it up and try fifth root of $32^3$, you have to root a 5-digit number for no reason.

</div>

## Worked example

Find the value of $16^{3/4}$.

**Step 1: Read the index.** $\tfrac{3}{4}$ means fourth root then cube.

**Step 2: Take the fourth root.** $16 = 2^4$, so $\sqrt[4]{16} = 2$.

**Step 3: Cube the result.** $2^3 = 8$.

**Answer:** $\boxed{8}$. **[M1 for using the fractional-index rule (root then power); A1 for the answer]**

Full marks $= 2$.

## Common mistakes

- Reading $a^{1/2}$ as "half of $a$". It's the square root, not $\tfrac{a}{2}$. So $9^{1/2} = 3$, NOT $4.5$.
- Reading $a^{m/n}$ as "$\tfrac{m}{n}$ of $a$". The fraction is the index, not a coefficient.
- Doing the power before the root. $8^{2/3}$: cube-root first (giving $2$), then square (giving $4$). Don't square $8$ to get $64$ first.
- Treating a negative fractional index as just negative. $25^{-1/2} = \tfrac{1}{5}$, not $-5$.

## Quick summary

- $\textcolor{#fff067}{a}^{\textcolor{#00abfa}{1/n}} = \sqrt[\textcolor{#00abfa}{n}]{\textcolor{#fff067}{a}}$. Denominator $=$ which root.
- $\textcolor{#fff067}{a}^{\textcolor{#00abfa}{m/n}} = \left(\sqrt[\textcolor{#00abfa}{n}]{\textcolor{#fff067}{a}}\right)^{\textcolor{#00abfa}{m}}$. Root first, then power.
- $a^{-m/n} = \dfrac{1}{a^{m/n}}$. The minus reciprocates as usual.
- For roots to be nice, the base is usually a perfect $n$th power. $32^{3/5}$ works because $32 = 2^5$.
