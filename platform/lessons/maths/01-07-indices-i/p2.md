## Why this matters

Cambridge will give you expressions like $5^{-2}$, $\left(\tfrac{2}{3}\right)^{-1}$, or $\tfrac{3^2}{3^5}$ and expect a clean numerical answer. The two new ideas are: **zero index gives 1**, and **negative index gives a reciprocal**. Once you have those, every Paper 1 indices question becomes mechanical.

## Zero index

Any non-zero number raised to the power **<span style="color:#00abfa">0</span>** is **<span style="color:#0fee89">1</span>**:

$$\textcolor{#fff067}{a}^{\textcolor{#00abfa}{0}} \;=\; \textcolor{#0fee89}{1}$$

The proof is one line. By Rule 2 from p1, $\tfrac{a^m}{a^m} = a^{m-m} = a^0$. But the same fraction is also a number divided by itself, which is $1$. So $a^0$ must equal $1$ for the rules to stay consistent.

Examples (all true regardless of the base):

- $7^0 = 1$
- $(-12)^0 = 1$
- $\left(\tfrac{3}{8}\right)^0 = 1$
- $(1.7)^0 = 1$

The only thing left undefined is $0^0$, which Cambridge won't ask about.

## Negative index

A **<span style="color:#ff4670">negative</span>** index means take the **reciprocal** (flip):

$$\textcolor{#fff067}{a}^{\textcolor{#ff4670}{-n}} \;=\; \dfrac{\textcolor{#0fee89}{1}}{\textcolor{#fff067}{a}^{\textcolor{#00abfa}{n}}}$$

So the minus sign in the index doesn't make the answer negative. It moves the power to the **denominator**. The base stays positive.

Why this rule? Use Rule 2 again: $\tfrac{a^m}{a^n} = a^{m-n}$. If $n \gt m$ then the index goes negative, but the value is $\tfrac{1}{a^{n-m}}$. Setting $m = 0$ gives the rule $a^{-n} = \tfrac{1}{a^n}$ directly.

## Negative index of a fraction

When the base is itself a fraction, a negative index just **flips the fraction** (reciprocal of a fraction is the fraction upside-down):

$$\left(\dfrac{a}{b}\right)^{-n} \;=\; \left(\dfrac{b}{a}\right)^{n}$$

Examples:

- $\left(\tfrac{2}{3}\right)^{-1} = \tfrac{3}{2}$
- $\left(\tfrac{2}{3}\right)^{-2} = \left(\tfrac{3}{2}\right)^{2} = \tfrac{9}{4}$
- $\left(\tfrac{1}{5}\right)^{-3} = 5^3 = 125$

This is a fast trick on Paper 1: if you see a fraction with a negative index, flip and proceed normally.

<div class="trap-callout">

**Trap: a negative index NEVER produces a negative answer.** $2^{-3} = \tfrac{1}{8}$, not $-8$. The minus sign reciprocates; it doesn't change the sign of the value. The only way to get a negative answer is if the base itself is negative, e.g. $(-2)^3 = -8$.

</div>

## Worked example

Find the value of $\left(\dfrac{3}{4}\right)^{-2} + 5^0$.

**Step 1: Handle the fraction with negative index.** Flip the fraction, then square.

$$\left(\dfrac{3}{4}\right)^{-2} \;=\; \left(\dfrac{4}{3}\right)^{2} \;=\; \dfrac{16}{9}$$

**Step 2: Handle the zero index.** Anything to the power $0$ is $1$.

$$5^0 \;=\; 1$$

**Step 3: Add.** Common denominator $9$:

$$\dfrac{16}{9} + 1 \;=\; \dfrac{16}{9} + \dfrac{9}{9} \;=\; \dfrac{25}{9}$$

**Answer:** $\boxed{\dfrac{25}{9}}$. **[M1 for the reciprocal-and-square; B1 for the zero index; A1 for the addition]**

Full marks $= 3$.

## Common mistakes

- Treating $5^0$ as $0$. It's $1$, always (for non-zero base).
- Treating $2^{-3}$ as $-8$. The minus moves the power to the denominator: $\tfrac{1}{8}$.
- Treating $\left(\tfrac{2}{3}\right)^{-1}$ as $-\tfrac{2}{3}$. It's $\tfrac{3}{2}$, the reciprocal.
- For $\tfrac{3^2}{3^5}$, computing $9 \div 243$ instead of using the rule $3^{-3}$. The rule keeps the base and just gives you a negative index.

## Quick summary

- $\textcolor{#fff067}{a}^{\textcolor{#00abfa}{0}} = \textcolor{#0fee89}{1}$ for any non-zero $a$.
- $\textcolor{#fff067}{a}^{\textcolor{#ff4670}{-n}} = \dfrac{1}{\textcolor{#fff067}{a}^{\textcolor{#00abfa}{n}}}$. The minus reciprocates.
- $\left(\tfrac{a}{b}\right)^{-n} = \left(\tfrac{b}{a}\right)^{n}$. Flip the fraction, drop the minus.
- A negative index never makes the answer negative.
