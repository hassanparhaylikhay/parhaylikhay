## What you learned in 9.7

- **Histograms** display continuous data with possibly unequal class widths.
- **Frequency density** $= \dfrac{\text{frequency}}{\text{class width}}$ goes on the y-axis.
- **Class width** determines bar width on the x-axis.
- **Bar AREA** = frequency, the fundamental property.
- No gaps between bars; widths and heights reflect data, not visual convention.

## Comprehensive worked example

Below is a partial frequency table for ages of $80$ people surveyed:

| Age class | Frequency |
|--|--|
| $0$-$10$ | $8$ |
| $10$-$20$ | $14$ |
| $20$-$40$ | $32$ |
| $40$-$50$ | $14$ |
| $50$-$80$ | $12$ |

(a) Compute the class widths and frequency densities.

(b) The histogram for this data has a bar height of $1.6$ for the $0$-$10$ class. Hmm, verify whether that''s right.

(c) Estimate how many people are in the $20$-$40$ class from the histogram: the bar has height $1.6$ and width $20$. (Verify against the table.)

**Part (a).**

| Class | Width | Frequency | Density |
|--|--|--|--|
| $0$-$10$ | $10$ | $8$ | $0.8$ |
| $10$-$20$ | $10$ | $14$ | $1.4$ |
| $20$-$40$ | $20$ | $32$ | $1.6$ |
| $40$-$50$ | $10$ | $14$ | $1.4$ |
| $50$-$80$ | $30$ | $12$ | $0.4$ |

**[B2 for all five densities; B1 for partial]**

**Part (b).** $0$-$10$ class width $= 10$, frequency $= 8$, density $= 0.8$, not $1.6$. The given height $1.6$ is wrong for this class. **[B1 for noticing the discrepancy]**

**Part (c).** $20$-$40$ bar has density $1.6$ and width $20$, so frequency $= 1.6 \times 20 = 32$. This matches the table. $\boxed{32}$. **[B1]**

Full marks $= 4$.

## Quick summary

- Frequency density goes on the y-axis.
- Bar widths reflect class widths.
- AREA = frequency, always.
- No gaps (continuous data).
