## Why this matters

Suppose you have a piece of land shaped like an L (a square plus a rectangle attached to one side). To use it efficiently, you'd want to fill in the missing corner to make it a full square. **Completing the square** in algebra is exactly this idea applied to expressions: we add a small "corner" to turn $x^2 + bx$ into a perfect square. The trick is then subtracting that same corner so the value doesn't change.

This is one of the most useful techniques in O-level algebra: it derives the quadratic formula (you'll see in 2.5 p4), it finds the minimum or maximum of a quadratic (used heavily in 2.11 sketching curves), and it's a stepping stone to several Paper 2 problems. Once you see it geometrically, the algebra becomes obvious.

## The geometric idea

Start with $x^2 + 6x$. Picture it as:

- A square of side $x$ (area $x^2$)
- A rectangle of width $x$ and height $6$ (area $6x$)

The total is $x^2 + 6x$, but the shape is **L-shaped**, not a square. To turn it into a square, **split the $6x$ rectangle into two equal halves of $3x$ each, place one on each side of the $x \times x$ square, and fill in the missing corner with a $3 \times 3$ square** (area $9$).

The result is a complete square of side $\textcolor{#0fee89}{(x + 3)}$, area $\textcolor{#0fee89}{(x + 3)^2}$.

But we **added** $\textcolor{#ff4670}{9}$ to do this. So the original $x^2 + 6x$ equals the new square **minus** that added $\textcolor{#ff4670}{9}$:

$$x^2 + 6x \;=\; \textcolor{#0fee89}{(x + 3)^2} - \textcolor{#ff4670}{9}$$

## The algebraic recipe

For $x^2 + \textcolor{#fff067}{b}x$:

1. Halve $\textcolor{#fff067}{b}$. Call the result $\textcolor{#0fee89}{\tfrac{b}{2}}$.
2. Add and subtract $\textcolor{#ff4670}{\left(\tfrac{b}{2}\right)^2}$ in one motion: $x^2 + \textcolor{#fff067}{b}x + \textcolor{#ff4670}{\left(\tfrac{b}{2}\right)^2} - \textcolor{#ff4670}{\left(\tfrac{b}{2}\right)^2}$.
3. The first three terms now form a perfect square: $\textcolor{#0fee89}{\left(x + \tfrac{b}{2}\right)^2}$.
4. Result: $x^2 + \textcolor{#fff067}{b}x = \textcolor{#0fee89}{\left(x + \tfrac{b}{2}\right)^2} - \textcolor{#ff4670}{\left(\tfrac{b}{2}\right)^2}$.

**Example.** $x^2 + \textcolor{#fff067}{6}x$.

- Halve $\textcolor{#fff067}{6}$: get $\textcolor{#0fee89}{3}$.
- $\textcolor{#ff4670}{\left(\tfrac{b}{2}\right)^2 = 9}$.
- Completed form: $\textcolor{#0fee89}{(x + 3)^2} - \textcolor{#ff4670}{9}$.

Verify by expanding: $(x + 3)^2 - 9 = x^2 + 6x + 9 - 9 = x^2 + 6x$ ✓.

**Example with a negative $b$.** $x^2 - 8x$.

- Halve $-8$: get $-4$.
- $(-4)^2 = 16$.
- Completed form: $(x - 4)^2 - 16$.

The sign inside the bracket matches the sign of $\tfrac{b}{2}$.

## With a constant added: $x^2 + bx + c$

Same recipe, then carry the leftover constant.

**Example.** $x^2 + 4x + 7$.

- Halve $4$: get $2$.
- $\left(\tfrac{b}{2}\right)^2 = 4$.
- $x^2 + 4x = (x + 2)^2 - 4$.
- Add the original $+7$: $(x + 2)^2 - 4 + 7 = (x + 2)^2 + 3$.

So $x^2 + 4x + 7 = (x + 2)^2 + 3$.

A cleaner way to track it: write $c$ as $\left(\tfrac{b}{2}\right)^2 + \text{(something)}$, where the something is what gets carried.

## When $a \ne 1$: factor it out first

For $ax^2 + bx + c$ with $a \ne 1$, **factor $a$ from the first two terms** before completing.

**Example.** $2x^2 + 8x + 5$.

**Step 1: Factor $2$ from the $x$-terms.**

$$2x^2 + 8x + 5 \;=\; 2(x^2 + 4x) + 5$$

**Step 2: Complete the square inside the bracket.**

$$x^2 + 4x \;=\; (x + 2)^2 - 4$$

**Step 3: Substitute back.**

$$2((x + 2)^2 - 4) + 5 \;=\; 2(x + 2)^2 - 8 + 5 \;=\; 2(x + 2)^2 - 3$$

Don't forget to multiply both terms inside the bracket by the $2$ when expanding back.

## What completed-square form tells you

The form $(x + h)^2 + k$ instantly reveals two things:

- **Minimum (or maximum) value** of the expression. $(x + h)^2 \ge 0$ always, so the minimum of $(x + h)^2 + k$ is $k$, reached when $x = -h$.
- **The vertex of the parabola** $y = (x + h)^2 + k$ is at $(-h, k)$.

**Example.** $(x - 3)^2 + 5$. The minimum is $5$, reached at $x = 3$.

**Example.** $-(x + 1)^2 + 7$. The leading coefficient is negative, so this is an upside-down parabola. The MAXIMUM is $7$, reached at $x = -1$.

This will be the bedrock of sketching quadratics in 2.11.

## Worked example

Express $x^2 + 10x + 21$ in the form $(x + h)^2 + k$, and state the minimum value.

**Step 1: Halve $b = 10$.** $\tfrac{b}{2} = 5$.

**Step 2: Compute $\left(\tfrac{b}{2}\right)^2$.** $5^2 = 25$.

**Step 3: Rewrite.**

$$x^2 + 10x + 21 \;=\; (x + 5)^2 - 25 + 21 \;=\; (x + 5)^2 - 4$$

**Step 4: State the minimum.** $(x + 5)^2 \ge 0$, so the minimum is $-4$, reached at $x = -5$.

**Answer:** $\boxed{(x + 5)^2 - 4}$, minimum value $\boxed{-4}$. **[M1 for the completed form; A1 for $h, k$; B1 for the minimum]**

Full marks $= 3$.

## Common mistakes

- Forgetting to subtract the added square. $x^2 + 6x \ne (x + 3)^2$; it's $(x + 3)^2 - 9$.
- Sign error on $h$. For $x^2 - 8x$, $h = -4$, so the bracket is $(x - 4)$, not $(x + 4)$.
- Skipping the factor-out step when $a \ne 1$. $2x^2 + 8x + 5 \ne (x + 4)^2 \cdots$; you must factor $2$ first, then complete inside, then re-multiply.
- Mixing up the sign of $k$. The minimum value of $(x + h)^2 + k$ is $k$ with the sign it has, no need to change it.

## Quick summary

- For $x^2 + bx$: completed form is $\left(x + \tfrac{b}{2}\right)^2 - \left(\tfrac{b}{2}\right)^2$.
- For $x^2 + bx + c$: same idea, then add $c$ to the leftover.
- For $ax^2 + bx + c$ with $a \ne 1$: factor $a$ from the first two terms first.
- Completed form $(x + h)^2 + k$ instantly gives **minimum** $= k$ at $x = -h$.
- Always verify by expanding the bracket back.
