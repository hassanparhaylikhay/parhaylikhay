## What you should know by now

If you've worked through P1 to P2 you can:

- State the perpendicular condition: $m_1 \times m_2 = -1$, equivalently $m_2 = -\dfrac{1}{m_1}$.
- Find the perpendicular gradient by "flip and negate".
- Find the equation of a perpendicular line through a given point.
- Find the equation of the perpendicular bisector of $AB$ using the four-step recipe (midpoint → gradient → perp gradient → equation).

## Marking patterns at a glance

For "find perpendicular line through point":

- **B1** for the perpendicular gradient (correctly negated and reciprocated).
- **M1** for substituting the point into $y = mx + c$.
- **A1** for the final equation.

For "perpendicular bisector":

- **B1** for the midpoint.
- **B1** for the gradient of $AB$.
- **B1** for the perpendicular gradient.
- **M1** for substituting midpoint into $y = mx + c$.
- **A1** for the final equation.

## Worked example: perpendicular bisector

Given $A(-3, 1)$ and $B(5, 7)$, find the equation of the perpendicular bisector of $AB$ in the form $y = mx + c$.

**Step 1: midpoint.**

$$M = \left(\dfrac{-3 + 5}{2},\; \dfrac{1 + 7}{2}\right) = (1, 4)$$

**Step 2: gradient of $AB$.**

$$m_{AB} = \dfrac{7 - 1}{5 - (-3)} = \dfrac{6}{8} = \dfrac{3}{4}$$

**Step 3: perpendicular gradient.**

$$m_\perp = -\dfrac{4}{3}$$

**Step 4: substitute midpoint $(1, 4)$ into $y = -\dfrac{4}{3}x + c$.**

$$4 = -\dfrac{4}{3}(1) + c$$

**Step 5: solve.**

$$4 = -\dfrac{4}{3} + c \;\Rightarrow\; c = 4 + \dfrac{4}{3} = \dfrac{16}{3}$$

**Answer:** $y = -\dfrac{4}{3}x + \dfrac{16}{3}$. **[B1 midpoint; B1 gradient AB; B1 perp gradient; M1 substitute; A1 final]**

Full marks $= 5$.

## Quick reference

- Perpendicular gradient: flip + negate, i.e., $m_2 = -\dfrac{1}{m_1}$.
- Test: $m_1 \times m_2 = -1$.
- Perpendicular bisector: midpoint + perpendicular gradient + equation.
- Horizontal ⊥ Vertical (and vice versa).
