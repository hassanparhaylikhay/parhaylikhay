You've now seen everything Cambridge tests in 1.4. Three forms (<span style="color:#00abfa;font-weight:600">fraction</span>, <span style="color:#fff067;font-weight:600">decimal</span>, <span style="color:#0fee89;font-weight:600">percentage</span>) for the same value, plus the recurring-decimal special case.

## The skills you should have

- **Identify** proper, improper, and mixed fractions; convert mixed ↔ improper.
- **Simplify** any fraction to lowest terms using the HCF.
- **Convert** between fractions and terminating decimals, both directions.
- **Convert** between decimals and percentages (shift two places).
- **Convert** between fractions and percentages (via decimals).
- **Compare/order** values given in mixed forms by converting to a common form first.
- **Read and write** dot notation for recurring decimals.
- **Convert** recurring decimals to fractions using the algebraic method.

## Marking patterns

| Question style | Marks | Notes |
|---|---|---|
| "Write $\tfrac{n}{m}$ as a decimal" | 1 | Direct division; recall list saves time |
| "Write $0.dd$ as a fraction in simplest form" | 1 | Place value + simplify |
| "Convert $X\%$ to a fraction" | 1 | Over 100, simplify |
| "Order these values smallest to largest" | 2 | M1 conversion to common form, A1 correct order |
| "Write $0.\dot{a}\dot{b}$ as a fraction in simplest form" | 2 | M1 algebra setup, A1 simplified fraction |

## The single biggest mistake

Forgetting to **simplify**. Cambridge mark schemes generally credit only the lowest-terms answer. $\tfrac{6}{8}$ might lose the A1 mark even though it equals $\tfrac{3}{4}$. Check every fraction answer for common factors before writing it down.
