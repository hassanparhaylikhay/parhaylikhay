## Why this matters

A cricket score doubles every over: $2, 4, 8, 16, 32, \dots$. To find which over the score reached $32$, you ask "what power of $2$ gives $32$?" The answer is $5$, because $2^5 = 32$. That's an **index equation**: the unknown sits in the index, and you solve by **matching bases on both sides**.

Cambridge tests this directly on Paper 1 (e.g., "solve $32^x = 2$") and inside Paper 2 multi-part problems. Logarithms are NOT required at O-level; the syllabus expects you to spot a common base by inspection. Get fluent at recognising powers of $2, 3, 5$ up to about $5^4$, and these questions become free marks.

## The core idea

If two powers of the **same base** are equal, their **indices must be equal**.

$$\textcolor{#fff067}{a^m} = \textcolor{#fff067}{a^n} \quad \Longleftrightarrow \quad m = n$$

So the whole strategy is: **rewrite both sides as powers of the same base, then equate the indices.**

## Powers of common bases worth memorising

These are the bases Cambridge uses again and again:

| Base | Powers |
|---|---|
| $\textcolor{#0fee89}{2}$ | $2, 4, 8, 16, 32, 64, 128, 256$ |
| $\textcolor{#0fee89}{3}$ | $3, 9, 27, 81, 243$ |
| $\textcolor{#0fee89}{5}$ | $5, 25, 125, 625$ |
| $\textcolor{#0fee89}{4}$ | $4, 16, 64, 256$ (note: $4 = 2^2$) |

Whenever you meet a number on either side of an index equation, ask: **"Is this a power of $2$, $3$, or $5$?"** If yes, rewrite it that way.

## Worked example 1: simple base match

Solve $2^x = 32$.

**Step 1: Rewrite both sides with the same base.** $32 = 2^5$.

$$2^x \;=\; 2^5$$

**Step 2: Equate the indices.**

$$x = 5$$

Done. **[B1]**

## Worked example 2: power of a power

Solve $32^x = 2$.

The bases look different, but $32 = 2^5$, so we can rewrite the left.

**Step 1: Use base $2$.** $32 = 2^5$, so $32^x = (2^5)^x = 2^{5x}$.

$$2^{5x} \;=\; 2^1$$

**Step 2: Equate the indices.**

$$5x = 1 \;\Rightarrow\; x = \dfrac{1}{5}$$

So $x = \tfrac{1}{5}$. **[M1 for the rewrite; A1 for $x$]**

## Worked example 3: index expression on one side

Solve $5^{x + 1} = 25$.

**Step 1: Rewrite the right side.** $25 = 5^2$.

$$5^{x + 1} \;=\; 5^2$$

**Step 2: Equate the indices.**

$$x + 1 = 2 \;\Rightarrow\; x = 1$$

The "$x + 1$" is the entire index on the left; once bases match, the whole index expression equals the index on the right.

## Worked example 4: both sides need a rewrite

Solve $4^x = 8^{x - 1}$.

Neither side is a "nice" power, but both reduce to base $2$.

**Step 1: Rewrite using base $\textcolor{#fff067}{2}$.** $4 = \textcolor{#fff067}{2}^2$, $8 = \textcolor{#fff067}{2}^3$.

$$(2^2)^x \;=\; (2^3)^{x - 1}$$

$$2^{2x} \;=\; 2^{3(x - 1)}$$

**Step 2: Equate the indices.**

$$2x = 3(x - 1)$$

$$2x = 3x - 3$$

$$-x = -3$$

$$x = 3$$

The two-step structure (rewrite, then linear-equation-solve) is exactly what Cambridge wants to see.

<div class="trap-callout">

**Trap: don't equate bases when the indices differ.** If you see $2^x = 8^x$, the answer is NOT "any $x$ because the indices match". You must first match the BASE: $8 = 2^3$, so the equation is $2^x = 2^{3x}$, giving $x = 3x$, or $x = 0$.

</div>

## Worked example 5: rewriting with fractional indices

Solve $9^x = 27$.

Both $9$ and $27$ are powers of $3$.

**Step 1: Rewrite using base $3$.** $9 = 3^2$, $27 = 3^3$.

$$(3^2)^x \;=\; 3^3$$

$$3^{2x} \;=\; 3^3$$

**Step 2: Equate.**

$$2x = 3 \;\Rightarrow\; x = \dfrac{3}{2}$$

The answer is a fraction. That's fine; index equations often have fractional or negative solutions.

## Worked example

Solve $\dfrac{1}{16} = 2^x$.

**Step 1: Rewrite the left.** $16 = 2^4$, so $\tfrac{1}{16} = \tfrac{1}{2^4} = 2^{-4}$.

$$2^{-4} \;=\; 2^x$$

**Step 2: Equate indices.**

$$x = -4$$

**Answer:** $\boxed{x = -4}$. **[M1 for rewriting $\tfrac{1}{16}$ as $2^{-4}$; A1 for the value]**

Full marks $= 2$.

## Common mistakes

- Leaving the bases unmatched. $32^x = 2$ is NOT solved by "$x = \tfrac{1}{32}$" or any guess. Rewrite both sides using a common base FIRST.
- Forgetting the power-of-a-power rule when rewriting. $32^x = (2^5)^x = 2^{5x}$, not $2^{5+x}$.
- Treating $a^{x+1}$ as $a \cdot x + 1$. The index is the WHOLE expression $x + 1$. Don't multiply the base by it.
- Sign errors with fractions. $\tfrac{1}{16} = 2^{-4}$, not $2^{4}$.

## Quick summary

- Index equations: rewrite both sides as **powers of the same base**, then **equate the indices**.
- Memorise small powers of $2, 3, 5$: that's how you spot the common base.
- Use the power-of-a-power rule when rewriting: $a^{mn} = (a^m)^n$.
- Solutions can be whole numbers, fractions, or negatives.
