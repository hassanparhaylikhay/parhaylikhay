## Why this matters

Paper 2 of Cambridge 4024 is calculator-allowed. Many students still lose marks because they round mid-calculation, miss brackets, or copy down the wrong number of digits. This part covers the small habits that make calculator work clean and accurate.

## Rule 1: never round inside a calculation

If a question takes several steps, **do all of them at full precision** and only round the **final answer**. Rounding mid-way introduces errors that get amplified in later steps.

The early-rounding answer ($25.495$) is close but wrong. With chained calculations (especially involving squares and roots) the gap can grow.

**Practical workflow:** if you must store an intermediate, **use the calculator's memory or Ans key** instead of writing it down with limited digits. The Ans key gives you full precision automatically.

## Rule 2: use brackets to override BIDMAS

Calculators follow BIDMAS strictly. So $\tfrac{8 + 12}{4}$ entered as `8 + 12 ÷ 4` gives $8 + 3 = 11$, not $5$. To force the addition first, type `(8 + 12) ÷ 4`.

| Expression | Without brackets | With brackets |
|---|---|---|
| $\dfrac{8+12}{4}$ | $8 + 12 \div 4 = 11$ ✗ | $(8 + 12) \div 4 = 5$ ✓ |
| $\dfrac{6}{2 \times 3}$ | $6 \div 2 \times 3 = 9$ ✗ | $6 \div (2 \times 3) = 1$ ✓ |
| $-3^2$ | $-9$ | $(-3)^2 = 9$ |

The fraction bar acts like brackets on both top AND bottom. **If the question shows a fraction, type the top in brackets, then divide, then the bottom in brackets.**

## Rule 3: type whole expressions in one go

Modern Cambridge-approved calculators show what you type. **Type the whole expression**, check it on the screen, then press $=$. This avoids losing precision and makes errors easier to spot.

## Rule 4: read the display carefully

Calculator displays often **use a different format from the question**. The same number $0.45833\overline{3}$ might appear as:

- $0.4583333$ (truncated)
- $0.45\overline{8}33$ (with recurring bar)
- $\tfrac{11}{24}$ (fraction key)

**Always check what the question asks** ($P\%$, fraction, decimal, d.p., s.f.) and convert if needed. Don't just write down whatever the calculator shows.

## Rule 5: round only at the end

When the question asks for an answer "to $3$ s.f." or "to $2$ d.p.", apply the rule from 1.9 ONLY at the final step. Show the unrounded value first, then round.

**Example.** Compute $\dfrac{4.92 \times 7.13}{2.04}$, giving the answer to $3$ s.f.

- Type the whole expression. Calculator shows $17.1985\ldots$
- Round to $3$ s.f.: $17.2$.
- Final answer: $17.2$.

If you'd rounded mid-way ($4.92 \times 7.13 \approx 35.1$, then $\div 2.04 \approx 17.2$), you happen to get the same answer, but in trickier expressions you might lose 0.1 to early rounding.

## Worked example

Compute $\dfrac{(7.4)^2 - 12.5}{3.6}$, giving the answer to $3$ significant figures.

**Step 1: Type the full expression in one go.**

`( 7.4 x² − 12.5 ) ÷ 3.6 =`

**Step 2: Read the display.** The calculator shows $11.7833\overline{3}$ (or $11.78333333$).

**Step 3: Round to $3$ s.f.** Cut at 3 s.f.: $11.7\,|\,8333$. The next digit is $8 \ge 5$, round up.

$$11.7 \to 11.8$$

**Answer:** $\boxed{11.8}$ (to 3 s.f.). **[M1 for typing the whole expression with brackets; A1 for the rounded answer]**

Full marks $= 2$.

## Common mistakes

- Rounding the inputs first. $\sqrt{2}$ to $3$ s.f. is $1.41$, but using $1.41^2 = 1.9881$ instead of $2$ exactly loses precision.
- Forgetting brackets around the top of a fraction. $\tfrac{8+12}{4}$ is NOT `8+12÷4`.
- Copying the display digit-for-digit when the question asks for a rounded form.
- Not using the Ans key when continuing a calculation. Ans gives full precision.

## Quick summary

- <b style="color:#0fee89">Full precision</b> through every intermediate step. Round only at the end.
- Use <b style="color:#fff067">brackets</b> to enforce the order you want, especially for fractions.
- Type the whole expression in one go and check the screen before pressing $=$.
- Read the display carefully and convert to the form Cambridge asks for.
