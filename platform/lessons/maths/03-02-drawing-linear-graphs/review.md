## What you should know by now

If you've worked through P1 to P2 you can:

- Read the gradient and y-intercept off any equation in the form $y = mx + c$.
- Draw a line by plotting two points (intercepts or via gradient + intercept), then ruling through them.
- Convert from general form $ax + by = c$ to $y = mx + c$ by rearranging.
- Use the two-intercept trick directly without rearranging.
- Recognise vertical lines $x = k$ (gradient undefined) and horizontal lines $y = k$ (gradient $0$).

## Marking patterns at a glance

A typical Paper 1 line-drawing question awards:

- **B1** for one correct point.
- **B1** for a second correct point.
- **B1** for a properly ruled line through them.

For a "find the intercepts" question:

- **B1** for the x-intercept.
- **B1** for the y-intercept.

## Worked example

Draw the line $4x - 3y = 12$, showing both intercepts and stating the gradient.

**Step 1: x-intercept.** Set $y = 0$: $4x = 12 \Rightarrow x = 3$. Plot $(3, 0)$.

**Step 2: y-intercept.** Set $x = 0$: $-3y = 12 \Rightarrow y = -4$. Plot $(0, -4)$.

**Step 3: ruled line through both points.**

**Step 4: gradient.** Rearrange to $y = mx + c$: $-3y = -4x + 12 \Rightarrow y = \dfrac{4}{3}x - 4$. Gradient $= \dfrac{4}{3}$.

**Answer:** Line through $(3, 0)$ and $(0, -4)$. Gradient $\dfrac{4}{3}$. **[B1 each intercept; B1 ruled line; B1 gradient]**

Full marks $= 4$.

## Quick reference

- $y = mx + c$: $m$ gradient, $c$ y-intercept.
- $ax + by = c$: two-intercept trick - set $y = 0$ then $x = 0$.
- $x = k$: vertical, gradient undefined.
- $y = k$: horizontal, gradient $0$.
- Always use a ruler.
