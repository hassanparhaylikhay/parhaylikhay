## Why this matters

Cambridge often gives the equation of a line in the form $ax + by = c$ - the "general form". You have two paths: rearrange to $y = mx + c$ and use what you learnt in p1, or use the **two-intercept trick** directly. Both work; the trick is usually faster when the numbers are clean.

You also need to recognise the special vertical and horizontal forms $x = k$ and $y = k$.

## The two-intercept trick

Given $ax + by = c$, the line crosses the axes at two easy points:

- **x-intercept**: set $y = 0$ → $ax = c$ → $x = \dfrac{c}{a}$. Point $\left(\dfrac{c}{a}, 0\right)$.
- **y-intercept**: set $x = 0$ → $by = c$ → $y = \dfrac{c}{b}$. Point $\left(0, \dfrac{c}{b}\right)$.

Plot both, ruler through them, done. No rearrangement needed.

## Worked example: general form

Draw $3x + 2y = 12$.

**Step 1: x-intercept.** Set $y = 0$: $3x = 12 \Rightarrow x = 4$. Plot $(4, 0)$.

**Step 2: y-intercept.** Set $x = 0$: $2y = 12 \Rightarrow y = 6$. Plot $(0, 6)$.

**Step 3:** Draw a ruled line through both points.

**Answer:** Line through $(4, 0)$ and $(0, 6)$. **[B1 each intercept; B1 ruled line]**

Full marks $= 3$.

## Converting to $y = mx + c$

Sometimes you want the gradient explicitly. Rearrange:

$$3x + 2y = 12$$

Subtract $3x$:

$$2y = -3x + 12$$

Divide by $2$:

$$y = -\dfrac{3}{2}x + 6$$

Now you can read off $m = -\dfrac{3}{2}$ and $c = 6$. The line slopes downward.

## Vertical lines: $x = k$

A vertical line has the equation $x = k$ for some constant $k$. Every point on it has x-coordinate $k$:

- $x = 3$ passes through $(3, -2), (3, 0), (3, 1), (3, 5), \ldots$
- $x = 0$ is the y-axis itself.

You can't write $x = 3$ in the form $y = mx + c$ - vertical lines have **undefined gradient** (no rise/run, because run is zero).

## Horizontal lines: $y = k$

A horizontal line has equation $y = k$. Every point on it has y-coordinate $k$:

- $y = -2$ passes through $(-3, -2), (0, -2), (4, -2), \ldots$
- $y = 0$ is the x-axis itself.

In $y = mx + c$ form, this is just $y = 0 \times x + k$, so gradient is $0$ (flat).

## Worked example: special forms

Draw $x = -2$ and $y = 3$ on the same axes. State the gradient of each.

**Step 1: $x = -2$.** Vertical line through every point with $x$-coordinate $-2$. Pass through $(-2, 0), (-2, 3), (-2, -1), \ldots$

**Step 2: gradient of $x = -2$.** Vertical → undefined.

**Step 3: $y = 3$.** Horizontal line through every point with $y$-coordinate $3$. Pass through $(0, 3), (2, 3), (-1, 3), \ldots$

**Step 4: gradient of $y = 3$.** Horizontal → $0$.

**Answer:** $x = -2$ vertical, gradient undefined. $y = 3$ horizontal, gradient $0$. **[B1 each line; B1 each gradient]**

Full marks $= 4$.

## Common mistakes

- **Sign error when rearranging.** Subtract carefully: $3x + 2y = 12 \Rightarrow 2y = -3x + 12$, NOT $2y = 3x - 12$.
- **Confusing $x = 4$ with $y = 4$.** $x = 4$ is vertical (constant x). $y = 4$ is horizontal (constant y).
- **Calling vertical-line gradient "infinite".** Cambridge's accepted answer is "undefined". Don't say "infinity".
- **Trying to plot $x = 4$ from a single point.** Plot at least two points to fix the line, then ruler.

## Quick summary

- $ax + by = c$: use the two-intercept trick (set $y = 0$, then $x = 0$).
- Or rearrange to $y = mx + c$ to read off $m$ and $c$.
- $x = k$: vertical line, gradient undefined.
- $y = k$: horizontal line, gradient $0$.
