## What you should know by now

If you've worked through P1 to P2 you can:

- Use the formula $m = \dfrac{y_2 - y_1}{x_2 - x_1}$ to compute gradient from two points.
- Tell uphill ($m > 0$), downhill ($m < 0$), flat ($m = 0$), and vertical (undefined) from the value of $m$.
- Compare steepness via $|m|$.
- Read "rise per run" off any gradient.

## Marking patterns at a glance

For "find the gradient":

- **M1** for substituting both differences correctly.
- **A1** for the correct value (or "undefined" / "$0$" for special cases).

For "what kind of line":

- **B1** for a correct identification (horizontal / vertical / uphill / downhill).

## Worked example

A line passes through $A(-2, 5)$ and $B(4, -7)$.

(a) Find the gradient of $AB$.

(b) State whether the line is uphill or downhill.

**Step 1 (a).** Substitute into the formula:

$$m = \dfrac{-7 - 5}{4 - (-2)}$$

**Step 2 (a).** Simplify the differences:

$$m = \dfrac{-12}{6} = -2$$

**Step 3 (b).** $m < 0$, so the line is **downhill** (slopes from top-left to bottom-right).

**Answer (a):** $m = -2$. **[M1 substitute; A1 simplify]**

**Answer (b):** Downhill. **[B1]**

Full marks $= 3$.

## Quick reference

- $m = \dfrac{y_2 - y_1}{x_2 - x_1}$ - y on top, x on bottom.
- $m > 0$: uphill. $m < 0$: downhill.
- $m = 0$: horizontal. Undefined: vertical.
- Steepness: bigger $|m|$ = steeper.
