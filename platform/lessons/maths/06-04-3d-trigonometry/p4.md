## Two important "slants" on a pyramid

For a square-based pyramid, there are two lengths that look similar but live on different right triangles:

    <div>· <b style="color:#fff067">Slant edge</b>: apex to a base corner. The horizontal distance is from a corner to the centre = half the base diagonal.</div>
    <div>· <b style="color:#ff822c">Slant face height</b>: apex to the midpoint of a base edge. The horizontal distance is from the midpoint to the centre = half the base side.</div>

</div>

Both are right-triangle calculations from the apex. They differ only in the horizontal distance, half the base **diagonal** vs half the base **side**.

## The single trick: drop a perpendicular from the apex

Every pyramid question reduces to the same setup:

1. **Drop the perpendicular from the apex** straight down to the base. For a right pyramid, this lands at the **centre** of the base, and its length equals the pyramid's height $h$.
2. **Find the horizontal distance** from the foot of the perpendicular (the base centre) to whatever point on the base you care about, a corner or a midpoint.
3. **Apply 2D Pythagoras** in the vertical plane through the apex, the base centre, and that target point.

## Worked example: slant edge of a pyramid

A square-based pyramid has base $6$ cm × $6$ cm and height $8$ cm. Find the length of a slant edge (apex to a base corner).

<iframe src="/widgets/3d-step-explorer.html?preset=pyramid-slant-edge" style="width:100%;max-width:696px;height:600px;border:0;border-radius:10px;display:block;margin:18px auto" loading="lazy"></iframe>

The base diagonal is $\sqrt{6^{2}+6^{2}} = 6\sqrt{2}$. Half of it (from a corner to the centre of the base) is $3\sqrt{2} \approx 4.24$.

The slant edge, the half-diagonal, and the height form a right triangle in a vertical plane:

$$\text{slant edge}^{2} = (3\sqrt{2})^{2} + 8^{2} = 18 + 64 = 82$$

$$\text{slant edge} = \sqrt{82} \approx 9.06\;\text{cm}$$

**[M1 for half-diagonal $= 3\sqrt{2}$ or $\sqrt{18}$; M1 for slant$^{2} = 18 + 64$; A1 for $\sqrt{82}$ or $9.06$]**

Full marks $= 3$.

## Worked example: slant face height

Same pyramid (base $6$ × $6$, height $8$). Find the slant face height (from the apex perpendicular to a base edge).

The slant face height drops to a base **midpoint**, not a corner. The horizontal distance from a base midpoint to the centre of the base is $\tfrac{6}{2} = 3$.

The right triangle: slant face height, $3$ (horizontal), $8$ (height).

$$\text{slant face height}^{2} = 3^{2} + 8^{2} = 9 + 64 = 73$$

$$\text{slant face height} = \sqrt{73} \approx 8.54\;\text{cm}$$

Notice it's slightly shorter than the slant edge (because the horizontal leg is shorter, $3$ vs $3\sqrt{2} \approx 4.24$).

**[M1 for horizontal $= 3$; A1 for slant face height $\approx 8.54$ cm]**

Full marks $= 2$.

## Worked example: angle between a slant edge and the base

A square-based pyramid has base $6$ cm and height $8$ cm. Find the angle that a slant edge makes with the base.

<iframe src="/widgets/3d-step-explorer.html?preset=pyramid-edge-angle" style="width:100%;max-width:696px;height:600px;border:0;border-radius:10px;display:block;margin:18px auto" loading="lazy"></iframe>

Same right triangle as before: horizontal leg $3\sqrt{2}$ (from corner to centre), vertical leg $8$ (the height), slant edge as the hypotenuse.

We want the angle at the base corner. The opposite side is the height $8$, the adjacent is the horizontal $3\sqrt{2}$:

$$\tan\theta = \dfrac{8}{3\sqrt{2}} = \dfrac{8}{4.243} \approx 1.886$$

$$\theta = \tan^{-1}(1.886) \approx 62.0°$$

**[M1 for $\tan\theta = 8 / 3\sqrt{2}$ or equivalent; A1 for $\theta \approx 62.0°$]**

Full marks $= 2$.

## The angle between a slant FACE and the base is different

Same pyramid. Now find the angle between a slant face and the base.

The slant face's "tilt angle" is measured between the slant face height and its projection onto the base. The slant face height lives in a vertical plane through the apex and a base-edge midpoint. Its projection on the base is the segment from the centre to the midpoint, length $3$.

Right triangle: opp $= 8$ (height), adj $= 3$ (horizontal), the slant face height is the hypotenuse.

$$\tan\phi = \dfrac{8}{3} \approx 2.667$$

$$\phi = \tan^{-1}(2.667) \approx 69.4°$$

So the slant face makes a steeper angle with the base ($69.4°$) than the slant edge does ($62.0°$). Different right triangles, different answers. Always check which "slant" the question is asking about.

## Common mistakes

- **Using half the side instead of half the diagonal (or vice versa).** Corner → half-diagonal. Edge midpoint → half-side. Pick the right one.
- **Dropping the perpendicular to a corner.** For a right pyramid, the apex's foot is at the CENTRE of the base, not a corner.
- **Confusing slant edge with slant face height.** Different drops, different triangles, different answers.
- **Reading "slant" without checking which kind.** Always re-read.

## Quick summary

- For a right pyramid, the apex sits above the **centre** of the base. Drop the perpendicular; it equals the height $h$.
- Slant edge: drops from apex to a base CORNER. Horizontal leg = half the base diagonal.
- Slant face height: drops from apex to a base EDGE MIDPOINT. Horizontal leg = half the base side.
- Both are 2D right-triangle calculations once you have those two horizontal lengths.
- For angles: use $\tan^{-1}$(vertical / horizontal) in the same vertical right triangle.
