## Why this matters

A Cambridge "sketch" question is not the same as a "plot" question. Plotting means table of values plus tiny crosses on a grid (you did that in 2.10 p1). **Sketching** means a quick freehand drawing showing the SHAPE of the curve, with the most important features clearly labelled.

Cambridge usually awards a separate mark for each feature you mark on the sketch. For a quadratic that's typically:

- **B1** for the correct shape (U or ∩)
- **B1** for the y-intercept marked
- **B1** for the x-intercepts marked (or "no real roots" stated)
- **B1** for the turning point coordinates

So a sketch can be worth 3–4 marks. The skill is identifying the features quickly without plotting every point.

## Sketching a linear graph

Linear graphs come in three forms:

- $y = mx + c$
- $ax + by = c$
- $x = k$ (vertical line) or $y = k$ (horizontal line)

For any of these, find **two points** and join them with a ruler. The easiest two points are usually the **x-intercept** (set $y = 0$, solve for $x$) and the **y-intercept** (set $x = 0$, solve for $y$).

**Example.** Sketch $3x + 2y = 12$.

- y-intercept: $x = 0 \Rightarrow 2y = 12 \Rightarrow y = 6$. Point $(0, 6)$.
- x-intercept: $y = 0 \Rightarrow 3x = 12 \Rightarrow x = 4$. Point $(4, 0)$.

Draw a line through these two points. Done.

## Sketching a quadratic graph

A quadratic is $y = ax^2 + bx + c$. Four features to find:

### 1. Shape

- $a > 0$ → opens UPWARD (U-shape).
- $a < 0$ → opens DOWNWARD (∩-shape).

### 2. Y-intercept

Set $x = 0$. The y-intercept is just $c$ (the constant term). Always at $(0, c)$.

### 3. X-intercepts (roots)

Set $y = 0$ and solve $ax^2 + bx + c = 0$. Three cases:

- Factorises easily? Use it. e.g. $y = (x-3)(x+2)$ has roots $x = 3, -2$.
- Discriminant $b^2 - 4ac > 0$? Two real roots. Use the quadratic formula.
- Discriminant $b^2 - 4ac < 0$? No real roots. The curve doesn't touch the x-axis. State this on your sketch.

### 4. Turning point (vertex)

Use **completing the square** to rewrite $y = ax^2 + bx + c$ in the form

$$y = a(x - h)^2 + k$$

Then the turning point is at $(h, k)$. For a U-shape this is the **minimum**; for a ∩-shape it's the **maximum**.

## Worked example

Sketch $y = x^2 - 4x - 5$, showing the y-intercept, x-intercepts, and turning point.

**Step 1: shape.** Coefficient of $x^2$ is $+1$, so the parabola opens upward (U-shape).

**Step 2: y-intercept.** $x = 0 \Rightarrow y = -5$. Point $(0, -5)$.

**Step 3: x-intercepts.** Factor: $y = (x - 5)(x + 1)$. Roots: $x = 5$ and $x = -1$.

**Step 4: turning point by completing the square.**

$$y = x^2 - 4x - 5 = (x - 2)^2 - 4 - 5 = (x - 2)^2 - 9$$

Turning point: $(2, -9)$.

**Sketch.** A U-shape passing through $(-1, 0)$, $(5, 0)$, $(0, -5)$, with minimum at $(2, -9)$.

**Answer:** Shape: U. Y-intercept: $(0, -5)$. X-intercepts: $(-1, 0)$, $(5, 0)$. Turning point: $(2, -9)$. **[B1 shape; B1 y-intercept; B1 x-intercepts; B1 turning point]**

Full marks $= 4$.

## Common mistakes

- Drawing a sketch on grid paper and trying to plot it precisely. A sketch is freehand — the marks are for features, not accuracy.
- Forgetting to mark the turning point. Cambridge specifically awards a B1 for it.
- Using the formula $-b/(2a)$ for the turning point but not computing the y-coordinate. You need both.
- Reporting "no real roots" without stating it on the sketch. If the discriminant is negative, write "no real roots" next to your sketch.
- Confusing turning point form $(h, k)$ with the x-intercept. They're different points unless the discriminant is zero (touching x-axis).

## Quick summary

- Linear: find both intercepts, draw straight line through them.
- Quadratic: shape from sign of $a$; y-intercept from $c$; x-intercepts by factoring or formula; turning point by completing the square.
- Each labelled feature on your sketch is usually a separate B1 mark.
