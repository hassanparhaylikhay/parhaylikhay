## Why this matters

Counting fours in a one-day cricket innings: $4, 8, 12, 16, \dots$ : four more each over Babar Azam's at the crease. Or your monthly savings target: $100, 200, 300, \dots$. Or the WhatsApp forward-chain doubling: $2, 4, 8, 16, \dots$. Each is a **sequence**: an ordered list of numbers following a rule. Spotting and continuing the rule is the whole game in this part.

Cambridge tests three things on Paper 1: continue a sequence, describe its term-to-term rule, and (in p2 onwards) find a formula for the $n$-th term. This part nails the first two.

## What a sequence is

A **sequence** is an ordered list of numbers, called **terms**:

$$T_1, \;T_2, \;T_3, \;T_4, \;\dots, \;T_n, \;\dots$$

The subscript tells you the **position** of each term. $T_1$ is the first term, $T_2$ the second, and so on. $T_n$ is the **general term** : the term in position $n$.

## Term-to-term rules

The simplest way to describe a sequence is by saying how each term relates to the previous one. Common patterns:

| Rule | Example | Type |
|---|---|---|
| Add the same amount each time | $2, 5, 8, 11, \dots$ ($+3$) | $\textcolor{#fff067}{\text{linear / arithmetic}}$ |
| Multiply by the same amount each time | $3, 6, 12, 24, \dots$ ($\times 2$) | $\textcolor{#0fee89}{\text{geometric}}$ |
| Differences themselves grow steadily | $1, 4, 9, 16, \dots$ ($+3, +5, +7$) | $\textcolor{#00abfa}{\text{quadratic}}$ |
| Each term = sum of previous two | $1, 1, 2, 3, 5, 8, \dots$ | $\textcolor{#ff822c}{\text{Fibonacci-like}}$ |

The rule between adjacent terms is called the **term-to-term rule**. To find it:

1. Compute the differences between consecutive terms.
2. If those differences are **constant**, the sequence is **linear**: that constant is the **common difference**.
3. If the differences themselves change steadily (their differences are constant), the sequence is **quadratic**.
4. If the **ratios** of consecutive terms are constant, the sequence is **geometric**.
5. If each term is the sum of the previous two, it's Fibonacci-like.

## Walk: a linear sequence

Continue $2, 5, 8, 11, \dots$.

The differences: $5 - 2 = 3$, $8 - 5 = 3$, $11 - 8 = 3$. Constant $+3$. So the sequence is **linear** with common difference $\textcolor{#fff067}{3}$.

Next term: $11 + 3 = 14$. Then $14 + 3 = 17$, then $20$, $23$, ...

## Walk: a geometric sequence

Continue $3, 6, 12, 24, \dots$.

The ratios: $\dfrac{6}{3} = 2$, $\dfrac{12}{6} = 2$, $\dfrac{24}{12} = 2$. Constant ratio $\times 2$. So the sequence is **geometric**.

Next term: $24 \times 2 = 48$. Then $96$, $192$, ...

## Walk: a quadratic sequence

Continue $1, 4, 9, 16, \dots$.

The differences: $3, 5, 7$. NOT constant : they grow. But the differences of those differences (called **second differences**) are: $5 - 3 = 2$, $7 - 5 = 2$. Constant $2$. So the sequence is **quadratic**.

Next term: $16 + 9 = 25$ (because the next first-difference is $7 + 2 = 9$).

The terms are actually $1^2, 2^2, 3^2, 4^2, \dots$, the **square numbers**.

## Walk: Fibonacci-like

Continue $1, 1, 2, 3, 5, 8, \dots$.

Each term is the sum of the previous two: $1 + 1 = 2$, $1 + 2 = 3$, $2 + 3 = 5$, $3 + 5 = 8$. Next: $5 + 8 = 13$, then $21$, $34$, ...

## Reaching a specific term position

If a sequence is **linear** with common difference $d$ and first term $a$, the $n$-th term is

$$T_n = a + (n - 1) d$$

This is the same as **counting forward from the first term**: take $a$, add $d$ a total of $(n - 1)$ times.

**Example.** The 10th term of $5, 9, 13, 17, \dots$.

$a = 5$, $d = 4$, $n = 10$.

$$T_{10} = 5 + (10 - 1) \times 4 = 5 + 36 = 41$$

So the 10th term is $\boxed{41}$.

(In p2 we'll convert this to the cleaner $T_n = jn + k$ form Cambridge prefers.)

<div class="trap-callout">

**Trap: differences must be CONSTANT for the sequence to be linear.** $1, 3, 6, 10, \dots$ has differences $2, 3, 4, \dots$. Not constant : so NOT linear (it's actually triangular numbers, a quadratic sequence). Always check the differences before jumping to "+ this much each time".

</div>

## Worked example

The first four terms of a sequence are $7, 11, 15, 19$.

(a) State the term-to-term rule.

(b) Find the 20th term.

**Step 1 (a): Compute differences.** $11 - 7 = 4$, $15 - 11 = 4$, $19 - 15 = 4$. Constant.

**Rule:** "add $4$ to the previous term".

**Step 2 (b): Use the linear formula.** $a = 7$, $d = 4$, $n = 20$.

$$T_{20} = 7 + (20 - 1) \times 4 = 7 + 76 = 83$$

**Answer:** **(a)** $\boxed{\text{add } 4}$. **(b)** $\boxed{T_{20} = 83}$. **[B1 for the rule; M1 for substitution; A1 for the value]**

Full marks $= 3$.

## Common mistakes

- Saying "add $3$" when the first term wasn't included in the count. Always check the first difference, not just any random pair.
- Confusing first and second differences. Constant FIRST difference → linear. Constant SECOND difference → quadratic.
- Counting positions wrong. The 10th term needs $(10 - 1) = 9$ jumps of $d$, not $10$.
- Mistaking ratios for differences in geometric sequences. $3, 6, 12, 24$ is NOT "$+3, +6, +12$" : those happen to match here but break later. The rule is "$\times 2$".

## Quick summary

- A **sequence** is an ordered list of terms; $T_n$ is the term in position $n$.
- The **term-to-term rule** describes how each term relates to the previous one.
- **Linear** (arithmetic): constant first difference.
- **Geometric**: constant ratio.
- **Quadratic**: constant second difference.
- **Fibonacci-like**: each term = sum of the previous two.
- For linear: $T_n = a + (n - 1) d$.
