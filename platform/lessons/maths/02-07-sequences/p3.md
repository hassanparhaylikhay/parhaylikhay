## Why this matters

A tile-pattern problem: step 1 has $1$ tile, step 2 has $4$, step 3 has $9$, step 4 has $16$. The differences ($3, 5, 7$) themselves grow steadily : the **second** differences are constant. This is a **quadratic sequence**, and Cambridge gives it Paper 1 marks every year. Once you know the pattern is quadratic, finding the formula is a tidy 3-step recipe.

## The signature of a quadratic sequence

A sequence is **quadratic** if its **second differences** (differences of differences) are constant.

**Example.** $1, 4, 9, 16, 25, \dots$.

- First differences: $3, 5, 7, 9$.
- Second differences: $2, 2, 2$.

Constant second difference of $2$ → quadratic.

The nth term has the form

$$T_n \;=\; a n^2 + b n + c$$

with three coefficients to find. Different from the $jn + k$ of linear sequences.

## The recipe (3 steps)

To find the nth term of a quadratic sequence $T_1, T_2, T_3, T_4, \dots$:

**Step 1: Compute first and second differences.** If the second difference is constant (call it $D_2$), the sequence is quadratic with

$$\textcolor{#fff067}{a} \;=\; \dfrac{D_2}{2}$$

**Step 2: Set up two equations.** Use the first two terms:

$$T_1 = a + b + c \quad\text{and}\quad T_2 = 4a + 2b + c$$

**Step 3: Solve for $b$ and $c$.** With $a$ known from Step 1, you have two equations in two unknowns.

## Walk: a clean quadratic

Find the nth term of $2, 5, 10, 17, 26$.

**Step 1: Differences.**
- First: $3, 5, 7, 9$.
- Second: $2, 2, 2$. Constant.

So $a = \dfrac{2}{2} = 1$.

**Step 2: Two equations.**
- $T_1 = 1 + b + c = 2$, so $b + c = 1$.
- $T_2 = 4 + 2b + c = 5$, so $2b + c = 1$.

**Step 3: Solve.** Subtract the first from the second: $b = 0$. Then $c = 1$.

**Answer:** $T_n = n^2 + 1$.

**Check at $n = 5$:** $25 + 1 = 26$ ✓.

## Walk: with mixed coefficients

Find the nth term of $3, 8, 15, 24, 35$.

**Step 1: Differences.**
- First: $5, 7, 9, 11$.
- Second: $2$. Constant.

$a = 1$.

**Step 2: Two equations.**
- $T_1 = 1 + b + c = 3$, so $b + c = 2$.
- $T_2 = 4 + 2b + c = 8$, so $2b + c = 4$.

**Step 3: Solve.** Subtract: $b = 2$. Then $c = 0$.

**Answer:** $T_n = n^2 + 2n$.

## Cubic sequences (rare on Cambridge)

If first AND second differences both grow, but **third** differences are constant, the sequence is **cubic**: $T_n = an^3 + bn^2 + cn + d$ for some $a, b, c, d$.

The nth term of $1, 8, 27, 64, 125, \dots$ is $\boxed{n^3}$ : the cube numbers. Their first, second, and third differences are $7, 19, 37, \dots$ → $12, 18, 24 \dots$ → $6, 6, 6$. Constant third difference of $6$ matches the cubic coefficient pattern.

In Cambridge problems, cubic sequences typically appear as recognisable "obvious" forms like $n^3$, $n^3 + 1$, etc., rather than asking for the full coefficient hunt.

## Worked example

Find the nth term of $5, 11, 21, 35, 53, \dots$.

**Step 1: Differences.**
- First: $6, 10, 14, 18$.
- Second: $4, 4, 4$. Constant.

$a = 4 / 2 = 2$.

**Step 2: Two equations using $T_n = 2n^2 + bn + c$.**
- $T_1 = 2 + b + c = 5$, so $b + c = 3$.
- $T_2 = 8 + 2b + c = 11$, so $2b + c = 3$.

**Step 3: Solve.** Subtract: $b = 0$. Then $c = 3$.

**Answer:** $T_n = 2n^2 + 3$. **[M1 for $a$; M1 for the simultaneous; A1 for the formula]**

Full marks $= 3$.

## Common mistakes

- Computing first differences only, ignoring second differences. Quadratic sequences have CONSTANT SECOND differences, not constant first.
- Forgetting that the coefficient of $n^2$ is $\frac{D_2}{2}$, not $D_2$ itself. The "halve" step is essential.
- Setting up the simultaneous equations with the wrong $T_1, T_2$ values.
- Mistakenly applying the linear recipe (constant difference) to a quadratic sequence : only works if the FIRST differences are constant.

## Quick summary

- **Quadratic** sequence: constant second difference.
- nth term: $T_n = an^2 + bn + c$.
- Coefficient $a = \frac{1}{2} \times$ (second difference).
- Use $T_1$ and $T_2$ to set up two simultaneous equations; solve for $b$ and $c$.
- **Cubic** sequence: constant third difference. Cambridge usually asks only for recognisable forms like $n^3$.
