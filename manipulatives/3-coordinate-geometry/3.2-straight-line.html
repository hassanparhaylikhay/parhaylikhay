Equation of a Straight Line — y = mx + c
Adjust m (gradient) and c (y-intercept) to explore how each changes the line.
y = x + 0
m (gradient) 1
c (y-intercept) 0
Cambridge tip: read c directly from where the line crosses the y-axis, then use two points to find m = (y₂−y₁)÷(x₂−x₁). Write the equation as y = mx + c — leaving it as y − y₁ = m(x − x₁) loses the A1 if the form is specified.
