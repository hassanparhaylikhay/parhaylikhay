## 3. Geometric Proofs Using Vectors — Ratio and Division

### What the mark scheme rewards
- M1 for identifying correct vector route
- A1 for correct simplified final answer "with no errors"
- Intermediate vectors shown clearly

### Key examples from 2025 papers

**w25_11 Q26:** Triangle OAB, OA = a, OB = 4b. T on AB with AT:TB = 3:2.

**(a)** Find AB in terms of a and b.
- AB = AO + OB = −a + 4b = 4b − a
- Full answer: 4b − a [B1]

**(b)** Show that position vector of T is (2a + 12b)/5, equivalently written as (2/5)(a + 6b):
- OT = OA + AT = a + (3/5)AB = a + (3/5)(4b − a) = a + 12b/5 − 3a/5 = (2a/5) + (12b/5)
- = (2/5)(a + 6b) — shown
- MS confirmation: "M1 for correct vector route for OT soi; M1 for (3/5)(4b−a) oe; A1 leading to (2a + 12b)/5 with no errors"
- Full marks = 3 [M2A1]

**(c)** Q is on OB. QT = (1/5)(2a − 3b). Find OQ : QB.

The key is that Q lies on OB, so OQ must be a pure multiple of b (zero a-component).

Method: OQ = OT − QT (since OQ + QT = OT)
- OT = (2a + 12b)/5
- QT = (1/5)(2a − 3b) = (2a − 3b)/5
- OQ = (2a + 12b)/5 − (2a − 3b)/5 = (2a + 12b − 2a + 3b)/5 = 15b/5 = 3b

OQ = 3b (a-component = 0 ✓, confirming Q is on OB as required)

Since OB = 4b and OQ = 3b:
- QB = OB − OQ = 4b − 3b = b
- OQ : QB = 3b : b = 3 : 1

- MS answer: OQ : QB = 3 : 1 oe [3 marks]
- M2 for OT − QT correctly computed to give 3b (or equivalent route)
- M1 for OQ = OT + TQ or OQ = OT − QT or correct vector route attempted
- Full marks = 3

**w25_12 Q21(a)(i):** OPQR is a parallelogram. OP = **a**, OR = 2**b**. M is the midpoint of QR. N is on PQ with PN : NQ = 1 : 3. Find vector MQ.
- Q = **a** + 2**b**; M = midpoint of QR = (1/2)**a** + 2**b**
- MQ = Q − M = (1/2)**a**
- Full answer: (1/2)**a** [B1]
- Full marks = 1

**w25_12 Q21(a)(ii):** Using the same parallelogram, find vector NM.
- N = P + (1/4)PQ = **a** + (1/4)(2**b**) = **a** + (1/2)**b**
- NM = M − N = −(1/2)**a** + (3/2)**b**
- Full answer: (3/2)**b** − (1/2)**a**
- B1 for MQ = (1/2)**a** soi OR M1 for correct vector route along diagram
- Full marks = 2

**w25_12 Q21(b):** Line OP is extended to point X. MNX is a straight line. Find the position vector of X.
- X lies on OP extended → OX = k**a** (zero **b** component); set **b** component of line MNX to zero → k = 7/6
- Full answer: (7/6)**a**
- B1 for (1/6)**a** soi (intermediate step) OR scale factor 1/3 along MN soi
- Full marks = 2

**s25_23 Q22(b)(i):** Triangle with a centroid. Find the length OB (centroid divides median in 2:1 ratio from vertex).
- Centroid divides median in ratio 2:1 from the vertex
- M1 for MB method (finding midpoint B using median construction)
- M1 for OB = (2/3) × median length oe
- Full answer: OB = 19.6
- Full marks = 3

## 4. Vectors — Parallel Vectors and Ratios

### Key principle
- Two vectors are parallel if one is a scalar multiple of the other
- If P divides AB in ratio m:n, then AP = (m/(m+n)) × AB

### Key examples from 2025 papers

**w25_11 Q26(c):** Q divides OB; find OQ:QB
- Method: express OQ and QB in terms of a and b, then compare
- If OQ = λ × OB and QT is known → find λ → ratio = λ:(1−λ)
- Full answer: OQ : QB = 3 : 1
- Full marks = 3

## 5. Vectors on a Line — Finding a Point and Ratio

### Key examples from 2024 papers

**s24_11 Q25:** Triangle OAB. OA = a, OB = b. C is a point on OB extended, and X is a point defined by a vector route. Find the position vector of X.
- B2 for BX = 2a − (1/2)b oe OR CX = 2a − (1/2)b oe (intermediate vectors on the route)
- M1 for correct vector route for OX from O along the diagram's defined path
- B1 for OC = 4a soi (key intermediate)
- Full answer: OX = 2a + (1/2)b (or equivalent)
- Full marks = 3

**s24_12 Q25:** Triangle OAB with OA = a, AB = 2b − a. Find position vector OX where X is a defined point on the figure.
- Full answer: OX = 2a − b oe final answer
- B2 for BX = 2a − (1/2)b oe or CX = 2a − (1/2)b oe (intermediate route vectors)
- M1 for correct vector route for OX along lines of diagram
- B1 for OC = 4a soi
- Full marks = 3

**w24_12 Q26(b):** OAB with OA = a, AB = 2b − a. C divides AB in ratio 1:3 from A. Find OC.
- AC = (1/4) × AB... wait: AC = 4 × AB? Need to check. MS says AC = 4(2b − a) or BC = 3(2b − a).
- OC = OA + AC = a + 4(2b − a) oe → OC = 8b − 3a
- OR: OC = OB + BC = 2b + 3(2b − a) oe → same result
- M1 for AC = 4(their AB) or BC = 3(their AB) oe OR for a correct route for OC seen
- A1 for OC = 8b − 3a (with correct working shown)
- Full marks = 2

**w24_12 Q26(c):** Find ratio OQ : QB where OQ is part of OB.
- Answer: OQ : QB = 1/3 [B1]
- Note: this gives a ratio (likely OQ = (1/4)OB → OQ:QB = 1:3, answer 1/3 as a fraction)
- Full marks = 1

**w24_12 Q26(a):** AB = 2b − a final answer [B1]
- Full marks = 1

### Key principles confirmed by 2024 examples
- Express OC via two routes: OA + AC or OB + BC — both must give same result
- M1 for identifying the correct fraction of AB to reach the division point
- The final answer must be collected/simplified: e.g., 8b − 3a not a + 4(2b − a)

## Marking Traps — Vectors Topic

1. **Direction matters**: AB = −BA. Writing the wrong direction = automatic 0 for that mark.
2. **Ratio on a line**: If T divides AB in ratio 3:2, then AT = (3/5)AB NOT (3/2)AB. The fraction is 3/(3+2) = 3/5.
3. **"With no errors"**: The A1 for a "show that" vector proof requires NO errors in the working. One sign error = A0.
4. **Column vector format**: Must use column vector notation (top/bottom), not (x, y) format, unless the question specifically asks for coordinates.
5. **Magnitude**: |v| = √(x² + y²) — never forget the square root. Also (−3)² = 9, not −9.
6. **Centroid**: Divides median in ratio 2:1 from vertex (not 1:2). Very common error.
7. **Position vector vs displacement vector**: Position vector = vector from origin O. Displacement vector = vector between two points.
