# Cambridge 4024 O-Level Mathematics — General Marking Principles
**Sources:** All 8 papers from 2025 series (s25_12, s25_13, s25_22, s25_23, w25_11, w25_12, w25_21, w25_22) + all 8 papers from 2024 series (s24_11, s24_12, s24_21, s24_22, w24_11, w24_12, w24_21, w24_22) + all 8 papers from 2023 series (s23_11, s23_12, s23_21, s23_22, w23_11, w23_12, w23_21, w23_22)

---

## Mark Types — Definitions

| Mark | Name | Meaning |
|------|------|---------|
| **M** | Method mark | Awarded for a correct method or process. Does NOT depend on a correct final answer. |
| **A** | Accuracy mark | Awarded for a correct answer or value. Usually DEPENDS on the preceding M mark. |
| **B** | Independent mark | Awarded independently — does not depend on any other mark. |
| **FT** | Follow Through | Student can earn marks using their incorrect earlier answer if they apply it correctly. |
| **SC** | Special Case | An alternative award where the standard scheme does not apply — always stated explicitly. |
| **dep** | Dependent | An M or A mark that can only be awarded if a specific earlier mark was also awarded. |

---

## Abbreviations Used Across All 2025 Mark Schemes

| Abbreviation | Meaning |
|-------------|---------|
| **cao** | Correct answer only — no credit for equivalent forms unless stated |
| **oe** | Or equivalent — any mathematically equivalent form accepted |
| **isw** | Ignore subsequent working — once a correct answer is seen, later errors do not remove the mark |
| **nfww** | Not from wrong working — the correct answer must be obtained by a valid method |
| **soi** | Seen or implied — the value does not need to be explicitly written |
| **awrt** | Answers which round to — any answer that rounds to the stated value |
| **rot** | Rounded or truncated |

## The 6 Generic Marking Principles (appear in every 2025 mark scheme verbatim)

1. **Marks awarded in line with**: the specific mark scheme content, the skills defined, and standardisation scripts.
2. **Marks are always whole marks** — no half marks, no fractions.
3. **Marks awarded positively**:
   - Credit for correct/valid answers including beyond-syllabus methods
   - Marks are NOT deducted for errors
   - Marks are NOT deducted for omissions
   - Spelling/punctuation/grammar only penalised if specifically assessed
4. **Rules applied consistently** — including when students have not followed instructions.
5. **Use the full mark range** as defined in the mark scheme.
6. **Marks based solely on requirements** — not on grade thresholds or descriptors.

---

## The 6 Mathematics-Specific Marking Principles (appear in every 2025 mark scheme verbatim)

1. **Any correct method gets full marks** unless a specific method is required. Exception: scale drawings never get marks if a calculation is required.
2. **Non-integer answers** can be given as fractions, decimals or standard form unless specified. Ignore superfluous zeros if accuracy is unaffected.
3. **Alternative notation** (e.g. commas as decimal points) allowed if used consistently throughout.
4. **isw applies** — marks once gained cannot subsequently be lost. Wrong working after a correct answer is ignored.
5. **Misread rule**: if a candidate misreads a number (not a sign change that alters difficulty), award all marks earned and deduct just **1 A or B mark** for the misread.
6. **Recovery allowed** — a notation error in working where the next line clarifies intent is recoverable.

## How A Marks Work with M Marks

- **A marks depend on M marks**: "A1 dep on M1" means the A mark can only be given if the M mark was earned.
- **A0 if errors**: Once an equation is formed, any subsequent error forfeits the A mark.
- **nfww**: The correct numerical answer alone, without supporting valid working, does not earn an nfww mark.

---

## FT (Follow Through) Rules

- FT allows a student to gain marks using an incorrect earlier result, provided they apply it correctly going forward.
- "FT their [value]" means: use whatever the student obtained in the earlier part, apply it correctly in this part.
- FT marks can be B marks: "B1FT" means an independent mark but following through from an earlier part.
- FT does NOT apply if the error fundamentally changes the nature of the problem.
- Example (w25_11 Q14b): "FT (their 8) ÷ 10" — if the student got v = 6 instead of 8, they still earn the mark for 6 ÷ 10.

---

### "Strict FT their graph" — variant

Some graph-reading marks carry "**Strict FT their graph**" rather than plain FT. This means:
- The student's answer is correct **only relative to whatever they drew**, even if the drawn curve is wrong
- No mark if the student reads a value that would only be correct from the intended curve, not from their actual drawn curve
- The distinction matters when a student's curve is plausibly drawn but shifted — plain FT would accept consistent readings; Strict FT requires the reading to actually come off the student's drawn line, not from the examiner's ideal curve

---

## SC (Special Case) Rules

- SC marks are awarded when a student uses a wrong approach that happens to produce a partially valid result.
- Examples from 2025 papers:
  - "SC1 for answer 1225" (w25_11 Q6 — student multiplied instead of subtracting)
  - "SC1 for pair satisfying either equation" (s25_12 Q11c — simultaneous equations with no/wrong method)
  - "SC1 for 100/169 (with replacement)" (s25_23 Q23 — probability calculated with replacement instead of without)
  - "SC1 for three correct solutions [if M1 scored]" (w25_11 Q22c — graph intersection solutions)

## How Graph Questions Are Marked

### Plotting points:
- B marks for correctly plotted points: B1 for 2 correct, B2 for 4 correct, B3 for 6 correct — usually FT.
- Curves: "Correct smooth curve" — must pass through all plotted points smoothly.

### Drawing lines on graphs (to find intersections):
- M1 for drawing the correct line (even if short or unruled)
- A1/A2 for reading the correct intersection values within an acceptable range
- SC1 for correct solutions without the line being fully drawn

### Sketching:
- B marks for shape (positive cubic, U-shape, exponential etc.)
- B marks for correct intercepts marked
- B marks for turning point (TP) marked
- "Max 2 marks if sketch not correct"

---

## Geometry Reasoning Marks

- In angle questions, the **answer alone** may earn B1, but the **reason is often a separate B1**.
- Cambridge wants specific geometric reasons stated:
  - "angles in the same segment are equal"
  - "alternate segment theorem"
  - "angle at centre is twice angle at circumference"
  - "co-interior angles sum to 180"
  - "corresponding angles are equal"
  - "alternate angles are equal"
  - "isosceles triangle" (base angles equal)
  - "opposite angles of cyclic quadrilateral sum to 180°"
- Partial marks: often B1 for the angle value, B1 for the correct reason stated. Both needed for full marks.

### Multi-step proofs — double-B allocation

Some multi-step geometry proofs (typically 4 marks) split as:
- **B2 for the correct final angle/conclusion** (nfww — must arise from valid reasoning)
- **B2 for complete correct reasons for every step**

These are NOT paired per step. They are two independent holistic assessments. A student can earn B2 + B0 (correct answer, wrong/missing reasons) or B0 + B2 (all reasons stated but arithmetic error in an angle). The mark scheme then adds: **"Max 3 marks if any incorrect angles or reasons"** — a cap that prevents a student with errors from earning both full B2 blocks.

This structure appears on questions that say "give a reason for each step of your working" and carry 4 marks (e.g., w23_22 Q2(b): find angle ADC from diameter + angle given, 4 marks).

### Congruence Proofs — Marking Pattern

- **B1 for each correct statement with correct reason** (e.g., "OA = OB [equal radii]")
- Must name the **congruence condition** at the end: SSS, SAS, AAS, or RHS
- Three such statements + condition name = full marks (typically 3 marks)
- Cambridge accepts any valid complete congruence proof — multiple routes exist (e.g., SAS or RHS may both be valid for the same diagram)
- Leaving out the condition name at the end (just writing the three pairs) usually loses 1 mark

## Multi-Step Questions — Mark Dependencies

Structure commonly seen:
- M1 for setting up (e.g. writing the correct formula)
- M1/M2 for correct intermediate working
- A1 for correct final answer (dep on relevant M marks)
- B marks scattered for key intermediate values if method is correct

Example (w25_11 Q17a — prism volume show that):
- M1 for h² + 5² = 13² or equivalent
- M2 for ½ × 10 × √(13² − 5²) × 3
- A1/A2 leading to 180 — must show full correct working

---

## Simultaneous Equations — Marking Pattern

Consistent across all 2025 papers:
- M1 for correct elimination/substitution method
- A1 for each correct value (A2 total for both)
- A1 for one value correct
- SC1 for a pair of values satisfying EITHER (not necessarily both) original equations (awarded if A0)

---

## Factorisation — Marking Pattern

- B2 for complete correct factorisation
- B1 for partial correct factorisation (e.g., one factor correct)
- Specific "with ab = k" or "a + b = k" conditions stated for partial credit

---

## Quadratic Formula — Marking Pattern

- B2 for correct substitution into formula (discriminant seen or implied)
- B1 for discriminant only, or formula with one error
- B1 for correct roots (both)

---

## Vectors — Marking Pattern

- M1 for identifying a correct vector route
- A1 for correct simplified final answer
- "With no errors" stated for full A marks

---

## Probability — Marking Pattern

- M marks for identifying correct combinations
- Fractions must be in correct form (not mixed up numerator/denominator)
- SC1 for "with replacement" method when "without replacement" is required

---

## Standard Form — Marking Pattern

- B1 for correct decimal form seen
- B1/B2 for correct standard form
- "cao" frequently applied — must be in exact standard form a × 10^n where 1 ≤ a < 10

---

## Bounds / Error Intervals — Marking Pattern

- B1 for each bound
- "B1 for one correct or for both correct but reversed" — common formulation
- Upper bound calculation usually: upper bound of each × n + upper bound of addition term

---

## Construction Questions

- B2 for correct triangle with correct arcs shown
- B1 for correct triangle without arcs / with incorrect arcs
- Measurement of angles: B1 for reading within ±1° of examiner's measurement on their construction

---

## Transformation Questions — Required Elements

Every transformation description requires specific elements — missing any element loses marks:

| Transformation | Required elements |
|---------------|-------------------|
| Reflection | "Reflection" + equation of mirror line |
| Rotation | "Rotation" + angle + direction + centre |
| Translation | "Translation" + column vector |
| Enlargement | "Enlargement" + centre + scale factor |

Each element is typically B1. All elements together = full marks.

---

## Algebraic Fraction Questions — Marking Pattern

- M marks for correct removal of fractions / correct use of common denominator
- M marks (dep) for correct expansion of brackets
- A1 for final correct simplified form "with no errors or omissions"
- B marks for numerator/denominator correct separately before simplification

### isw on B marks for intermediate fraction components

When combining two fractions into one, the mark scheme often reads:
- "B1 for [correct numerator expression] oe **isw**"
- "B1 for [correct denominator] oe **isw**"

The **isw** here is critical: it means these B marks are locked in as soon as the correct numerator/denominator is seen, even if the student then simplifies incorrectly or makes an error in the final step. This is different from the final-answer A1, which carries "no errors or omissions".

Practical implication: a student who correctly writes the combined numerator (e.g., 3(2x+1)−7(x−5)) and the denominator (e.g., (2x+1)(x−5)) earns both B marks even if they then expand incorrectly and produce a wrong final fraction. They cannot earn the A1 for the final answer.

---

## Significant Figures / Accuracy Requirements

- "Give your answer correct to 2 decimal places" — B1 for seeing more accurate decimal, B1 for correct rounding
- "awrt" — any answer which rounds to the stated value is acceptable
- Premature rounding is penalised — an annotation exists specifically for this
- For trigonometry: intermediate values should be kept at full calculator precision until final answer

---

## Show That Questions

- Full marks ONLY if working is complete, correct, and contains no errors or omissions
- The answer is given — examiners checking the route, not just the destination
- "A1 After full working shown and no errors or omissions" (w25_11 Q24b)
- Cannot skip steps

---

## Matrices — Marking Pattern

⚠️ **Matrices were removed from the Cambridge 4024 syllabus for first examination from 2025. Entries below and in `maths-matrices.md` are for historical reference (2023–2024 papers) only.**

- **B1 per correct element** for matrix operations (addition, subtraction, multiplication)
- **B1 for 2 or 3 correct elements** (partial credit threshold when total is 4 elements)
- **Determinant**: B1 for correct det = ad − bc
- **Inverse**: M1 for correct determinant, B1 for correct adjugate, A1 for correct final inverse
- **Solving by matrix method**: M1 for writing AX = B, M1 for multiplying by inverse, A1 for each variable
- **SC1 for one correct value** when solving simultaneous equations via matrix method
- A common SC trap: SC1 for (x, −y) when answer is (x, y) — sign error on one variable

---

## ISW on Standard Form Conversions

When a question asks for an answer in standard form:
- **ISW any subsequent attempts to convert** to or from standard form
- The mark is earned when the correct standard form is first seen
- Example (s24_21 Q1d): "ISW attempts to convert to or from standard form" — B marks earned for correct standard form; later arithmetic on it is ignored
- This means a student who writes 2.813 × 10⁷ and then converts it to 28 130 000 still earns the B mark

---

## "A0 if any errors or omissions" — Multi-Step Algebraic Proofs

In questions where the target quadratic is GIVEN (e.g. "show that x² − 6x − 17 = 0"):
- The A1/A marks at the end carry a strict condition: **A0 if any errors or omissions** in the working
- This means a single sign error anywhere in the chain forfeits the final A mark
- Example (s24_21 Q10d): B4 marks awarded with "A0 if any errors or omissions" at each stage
- M marks can still be earned for correct partial steps even if the A0 condition is triggered
- This also appears in rearranging algebraic fractions: "with no errors seen leading to answers"

---

## Graphical Inequality Region — Marking Pattern

For questions asking to identify/shade a region defined by two or more inequalities:
- **B1 for each boundary line drawn correctly** (whether solid or dashed as appropriate)
- **B1 for the correct region shaded/indicated** (after lines are drawn)
- The region mark is separate from the line marks
- Example (s24_12 Q16): B1 for y ≤ 2x ruled; B1 for x + y ≤ 4 ruled; final mark for correct region
- If lines are drawn but wrong region shaded: earn line marks but lose region mark
- Reading inequalities from a graph: SC1 for correct equations (x = 4 and y = x + 1) without inequality signs

---

## What Scores Zero — Common Mistakes That Earn No Marks

- Scale drawing when calculation required
- Correct final answer with wrong/no method when nfww is specified
- Transformation with missing element (e.g., rotation without centre)
- Graph intersections read without drawing the required line (unless SC1 awarded)
- Decimal recurring not converted correctly for fractions
- Final answer not simplified when "final answer" is specified in mark scheme
- Factorisation left as product with a coefficient not factored out (mark scheme specifies "final answer")
- Matrix inverse attempted without finding determinant first
- Algebraic proof with any error/omission — A0 even if final answer matches given result

---

## Similarity — Mark Scheme Pattern (Area vs Volume)

Consistently applied across all papers:
- **Linear scale factor k**: found from a given ratio of lengths
- **Area ratio = k²**: M1 for squaring the linear scale factor
- **Volume ratio = k³**: M1 for cubing the linear scale factor
- When going backwards (area or volume given, find length): √ or ∛ the ratio first to get k, then multiply
- Partial credit: M1 for √(area ratio) or ∛(volume ratio) even if multiplication goes wrong

---

## "Max N marks if answer incorrect" — Rearranging Formulae

Seen consistently in questions where x appears on both sides (requires factorisation):
- "Maximum 2 marks if final answer not correct" (when full marks = 3)
- Means: M1 + M1 can be earned for partial steps even if the answer is wrong, but the third mark (A1) is the final answer mark
- This pattern also appears for inverse functions, rearranging with two x terms, and compound formula manipulation
- Strategy: show each algebraic step separately — each step is a separate M mark

---

## Compound Questions Crossing Two Topic Files

Some Cambridge questions span two topics — the mark scheme may be split differently than expected:
- A geometry question that uses trigonometry (e.g., prism cross-section height by Pythagoras, then volume)
- A sequences question whose answer is verified algebraically
- In these cases, the entry appears in both relevant topic files (geometry AND mensuration, algebra AND sequences) — this is intentional. Each file covers the question from its topic's angle.

---

## Tolerance Ranges on Graph Readings

Cambridge always states an acceptable range for graph readings:
- e.g., "x = −2.8 to −2.6" means any value in that interval is correct
- These ranges reflect the inherent imprecision of reading from a drawn curve
- A value just outside the range (e.g., −2.59 when range is −2.8 to −2.6) scores A0
- Ranges are always given in the mark scheme; never guess or assume a tolerance yourself

## Entries Marked "*Note: verify against QP*" — How to Handle

Some KB entries were written without access to the original question paper (QP) diagram or when pdftotext produced garbled output. These entries are flagged with a *Note:* line. When you encounter one:

- **The marking pattern is reliable**: M/A/B mark structure, the partial credit thresholds, and the "Full marks = N" are extracted from the mark scheme and can be trusted.
- **The specific numbers or expression may be wrong**: If the *Note* says "pdftotext may have dropped √" or "brackets reconstructed", treat the actual numbers/formula as approximate.
- **The method is reliable**: The general approach (e.g., "use cosine rule", "factorise out x") is always correct — it's the specific substituted values that may be off.
- **When marking a real student**: if their question matches the method described but uses different numbers than the flagged entry, apply the mark structure to their actual numbers.

## FT Dependency Chain — When It Breaks

FT does not apply when:
- The student's wrong earlier value fundamentally changes the nature of the calculation (e.g., a negative length makes a subsequent area formula meaningless)
- The error makes the later part significantly easier (removing difficulty)
- The mark scheme explicitly states "nfww" on the later part

In practice: most multi-part questions allow FT generously unless the subsequent part becomes trivial.

## Official Accuracy Requirements (from Cambridge 4024 Syllabus, 2025–2027)

*These are the syllabus-level rules, distinct from individual mark scheme notes.*

**Paper 2 (Calculator) defaults:**
- Non-exact numerical answers: give to **3 significant figures** unless a different accuracy is specified in the question
- Angles in degrees: give to **1 decimal place** unless a different accuracy is specified
- Do **not** round intermediate values — keep full calculator precision and only round the final answer
- If a later part of the question needs a value from an earlier part, use the unrounded value
- Use π from a calculator, or 3.142 if π is not available

**General accuracy rules (both papers):**
- Answers should be in their simplest form unless the question states otherwise
- "Exact values" → give in terms of π or in surd form (not a decimal approximation)
- Answers exact to 4 or 5 significant figures should **not** be rounded (leave them as-is)
- For "show that" or "prove" questions: working must include intermediate answers to **at least one more degree of accuracy** than the final stated result
- A numerical answer must not be given as a combination of fractions and decimals (e.g. 1/0.2 is **not** acceptable)

**Marking implication:** Premature rounding in working (e.g., using 3.46 when 3.464 was needed) is penalised — this is what "awrt" and the intermediate-accuracy rule protect against. When marking, check whether a wrong final answer is a rounding penalty rather than a method error.

## Formulas Given in the Examination (page 2 of every paper)

These formulas appear on page 2 of every 4024 question paper. Students do **not** need to memorise them — but they must know how to apply them correctly.

| Formula | Expression |
|---------|-----------|
| Area of triangle, base b, height h | A = ½bh |
| Area of circle, radius r | A = πr² |
| Circumference of circle, radius r | C = 2πr |
| Curved surface area of cylinder (radius r, height h) | A = 2πrh |
| Curved surface area of cone (radius r, slant l) | A = πrl |
| Surface area of sphere, radius r | A = 4πr² |
| Volume of prism, cross-section A, length l | V = Al |
| Volume of pyramid, base area A, height h | V = ⅓Ah |
| Volume of cylinder (radius r, height h) | V = πr²h |
| Volume of cone (radius r, height h) | V = ⅓πr²h |
| Volume of sphere, radius r | V = (4/3)πr³ |
| Quadratic formula (ax² + bx + c = 0, a ≠ 0) | x = (−b ± √(b²−4ac)) / 2a |
| Sine rule | a/sinA = b/sinB = c/sinC |
| Cosine rule | a² = b² + c² − 2bc cosA |
| Area of triangle | Area = ½ab sinC |

**What is NOT given (students must know from memory):**
- Pythagoras' theorem (a² + b² = c²)
- Basic trig ratios (SOH CAH TOA)
- Area of rectangle, parallelogram, trapezium
- Arc length and sector area formulas
- Standard form, index laws
- All algebra and number facts

**Marking implication:** If a student uses a formula from the given list incorrectly (e.g., uses curved surface area when total surface area was needed, omitting the base), it is a method error — they had access to the correct formula. No benefit of the doubt.

## Command Words — Official Definitions (Cambridge 4024 Syllabus, 2025–2027)

These are the official Cambridge meanings. When reading a question, the command word tells you exactly what the mark scheme expects.

| Command word | What it means | Marking implication |
|---|---|---|
| **Calculate** | Work out from given facts, figures or information | Full working expected; method marks apply |
| **Construct** | Make an accurate drawing | Arcs must be shown; B marks for accuracy within tolerance |
| **Determine** | Establish with certainty | Full justification needed, not just an answer |
| **Describe** | State the points of a topic / give characteristics and main features | Specific geometric language needed (e.g. transformation descriptions) |
| **Explain** | Set out purposes or reasons / make relationships between things clear / say why and/or how with relevant evidence | A reason is required — the angle value alone is not enough |
| **Give** | Produce an answer from a given source or recall/memory | Short answer expected; no working usually required |
| **Plot** | Mark point(s) on a graph | Each point must be within half the smallest grid square |
| **Show (that)** | Provide structured evidence that leads to a given result | Full working required with no errors or omissions; A0 if any step is skipped |
| **Sketch** | Make a simple freehand drawing showing the key features | Must show intercepts, turning points, asymptotes — not to scale |
| **State** | Express in clear terms | Brief answer acceptable; no justification needed |
| **Work out** | Calculate from given facts, figures or information with or without a calculator | Same as Calculate — full working expected |
| **Write** | Give an answer in a specific form | Must match the required form exactly (e.g. standard form, simplified fraction) |
| **Write down** | Give an answer without significant working | Answer only; no penalty if working is shown but not required |

**Key distinctions for marking:**
- "Write down" → no working penalty, but answer must be correct; a wrong answer with correct working may earn M marks if the mark scheme supports it
- "Show (that)" → the answer is given; full marks require every step shown with no errors; A0 even if final answer matches if a step is missing
- "Explain" vs "State" → Explain requires a reason; State allows a bare answer; "Describe a transformation" requires all geometric elements (see Transformation Questions section)
