## 1. Straight Line Graphs — Equation, Gradient, Intercept

### What the mark scheme rewards
- Gradient = (y₂ − y₁)/(x₂ − x₁) correctly calculated [M1]
- Substituting a known point to find c in y = mx + c [M1]
- Final equation in required form y = mx + c [A1]
- Perpendicular gradient = −1/m [B1 FT]

### Key examples from 2025 papers

**w25_21 Q16(a):** Equation of line through A(3, −2) and B(5, 4). Give in form y = mx + c.
- M1 for gradient = (4 − (−2))/(5 − 3) = 6/2 = 3
- M1 for substitution: −2 = 3(3) + c → c = −11
- Full answer: y = 3x − 11
- Full marks = 3

**w25_21 Q16(b):** Gradient of perpendicular line
- Answer: −1/3 oe [B1 FT for −1/(their 3)]
- Full marks = 1

**w25_22 Q18(a):** Gradient of line L: y = (1/5)x + 3
- Answer: 1/5 [B1]

**w25_22 Q18(b)(i):** Line M parallel to L, passes through A(15, 0). Show B = (0, −3).
- M1 for gradient of M = 1/5 (same as L)
- M1 for substituting (15, 0): 0 = (1/5)(15) + c → c = −3 → B = (0, −3)
- A1 dep on both M marks, "with no errors"
- Full marks = 3 (M2A1 — "show that" so full working required)

**w25_22 Q18(b)(ii):** Line N is perpendicular bisector of AB. Find x-intercept C.
- B4 for y = −5x + 36 oe (full equation of N found)
- B1 for midpoint of AB = (7.5, −1.5) oe soi
- M1 for gradient of N = −5 (= −1/(1/5))
- M1 for substituting midpoint into y = −5x + c
- M1 dep for y = 0 → x = 7.2
- Full answer: C = (7.2, 0)
- Full marks = 5

## 4. Reading from Graphs — Intersections

### What the mark scheme rewards
- M marks for drawing the correct rearranged equation as a straight line
- A marks for correctly reading the intersection values (within a tolerance range)
- SC1 for correct solutions without drawing the line (if M1 earned)

### What the rearrangement technique is

To solve f(x) = g(x) graphically when you have y = f(x) drawn:
- Rearrange to: f(x) − g(x) = 0, or draw y = g(x) and read intersections

### Key examples from 2025 papers

**w25_11 Q22(c):** Solve x³ − 7x + 1 = 0 using the graph y = x³ − 3x + 2

The graph already drawn is y = x³ − 3x + 2. To solve x³ − 7x + 1 = 0:
- Set x³ − 3x + 2 = mx + c such that intersections give x³ − 7x + 1 = 0
- x³ − 3x + 2 = 4x + 1 → x³ − 7x + 1 = 0 ✓
- So draw the line y = 4x + 1

- **Line to draw**: y = 4x + 1 (M2 for correctly drawn ruled line; M1 for short/unruled line or y = 4x + 1 seen)
- **Solutions**: x ≈ −2.8 to −2.6, 0.1 to 0.2, 2.4 to 2.7
- A2 for all 3 correct values; A1 for 2 correct values
- SC1 for 3 correct solutions if only M1 scored
- Full marks = M2A2 = 4

**w25_12 Q15(c):** Use the graph of y = x³ − 4x² + 12 to find the negative root of x³ − 4x² + 12 = 10 (or similar rearranged equation — one solution expected here).
- Answer: x in range −1.7 to −1.3 [B1 FT from their curve]
- Full marks = 1

**w25_12 Q15(d):** Solve x³ − 4x² + x + 4 = 0 using the graph y = x³ − 4x² + 12

The graph already drawn is y = x³ − 4x² + 12. To solve x³ − 4x² + x + 4 = 0:
- Set x³ − 4x² + 12 = mx + c such that intersections give x³ − 4x² + x + 4 = 0
- x³ − 4x² + 12 = 8 − x → x³ − 4x² + x + 4 = 0 ✓
- So draw the line y = 8 − x

- **Line to draw**: y = 8 − x (M2 for correctly drawn ruled line; M1 for short/unruled line or y = 8 − x seen)
- **Solutions**: x ≈ −0.9 to −0.7, 1.4 to 1.6, 3.2 to 3.5
- A2 for all 3 correct; A1 for 2 correct
- SC1 for 3 correct solutions if only M1 scored
- Full marks = M2A2 = 4

**s25_22 Q19(c):** A cubic curve is already drawn. Solve a rearranged cubic equation by drawing an appropriate horizontal line y = 7 on the same graph and reading the intersections.
- M1 for y = 7 drawn correctly (horizontal line)
- Solutions in range: −1.95 to −1.7; −0.8 to −0.5; 2.3 to 2.6
- A2 for all 3 correct values (dep on M1); A1 for 2 correct
- Full marks = M1A2 = 3

## 6. Speed-Time Graphs

### Key examples from 2025 papers

**w25_11 Q14(a):** Speed-time graph: Lia cycles 800m in 105s. Trapezoidal shape (0 to v in 10s, constant v from 10s to 105s). Find v.
- Accelerates from 0 to v in first 10s (triangle), then constant v for remaining 95s (rectangle)
- Area = ½ × 10 × v + 95 × v = 5v + 95v = 100v = 800 → v = 8
- M1 for ½(105 + (105−10))v = 800 or ½ × (10) × v + (105−10) × v = 800 oe
- Full answer: v = 8 nfww
- Full marks = 2

**w25_11 Q14(b):** Acceleration during first 10 seconds
- acceleration = (v − 0)/10 = 8/10 = 0.8 m/s²
- Answer: 8/10 oe [B1 FT (their 8) ÷ 10]
- Full marks = 1

## 7. Direct and Inverse Proportion — Graph Form

### Key examples from 2025 papers

**w25_22 Q20:** y is inversely proportional to (x − 3)². Given y = 4 when x = 7. Find y when x = −2.
- y = k/(x − 3)²
- At x = 7: 4 = k/(7 − 3)² = k/16 → k = 64
- At x = −2: y = 64/(−2 − 3)² = 64/25 = 2.56
- M2 for k = 64 seen and substituting x = −2 oe
- M1 for correct proportionality structure y = k/(x − 3)² oe
- Full answer: 2.56 oe
- Full marks = 3

## 8. Exponential Graphs — Solving with a Line

### When this appears
Questions where an exponential curve y = a^(x + k) is drawn and you must solve an equation of the form a^(x + k) = value by drawing a horizontal line or identify the algebraic link.

### What the mark scheme rewards
- M1 for algebraic manipulation showing the connection (e.g., 2^(x+3) = 8 × 2^x)
- A1 for correct algebraic simplification reaching 2^x = c
- M1 for drawing the horizontal line y = c on the graph
- A1 for reading the x-value from the intersection (within tolerance)

### Key examples from 2024 papers

**s24_21 Q8(a)(i):** y = 2^(x+3). Find y when x = −2.
- y = 2^(−2+3) = 2^1 = 2 → wait, answer is 6.4. Must be different question structure.
- Answer: 6.4 oe cao [B1]
- Full marks = 1

**s24_21 Q8(a)(iii)(a):** Show that 2^(x+3) = k leads to 2^x = c.
- 2^(x+3) = 2^x × 2^3 = 8 × 2^x [M1 — may be done in stages by dividing by 2 three times]
- Leading to: 2^x/5 = 1/2 × ... (algebraic chain)
- A1 for reaching 2^x = 5/2 shown correctly
- This tests recognising that a^(x+k) = a^x × a^k

**s24_21 Q8(a)(iii)(b):** Solve 2^(x+3) = k using the graph.
- Draw horizontal line y = 2.5 [M1]
- Read intersection: x = 3.5 to 3.8 [A1]
- Full marks = 2 (M1A1)

### Key rule for exponential solving:
- Always rewrite a^(x+k) as a^x × a^k before equating to a table value
- The horizontal line on the graph gives the approximate solution

## Marking Traps — Graphs Topic

1. **Plotting vs drawing**: Plotting points earns B marks (FT); drawing the curve earns a separate B mark. Don't forget to draw through ALL points smoothly.
2. **Graph intersections**: The correct line MUST be drawn for full M marks. Solutions read without the line drawn = SC1 only (if M1 earned).
3. **Tolerance ranges**: Solutions must be within the given range (e.g., "−1.95 to −1.7"). A value of −1.65 would be outside the range and score A0.
4. **Completing the square**: The structure 2(x − b)² + c requires the 2 to be factored out BEFORE completing the square. Missing the factor = wrong b value = wrong turning point.
5. **Gradient from two points**: Must use the correct sign — if the line goes up left-to-right, gradient is positive.
6. **Speed-time graph**: Area = distance. For triangles: ½ × base × height. For trapezoids: ½(a + b) × h. Wrong shape formula = M0.
7. **Sketch vs draw**: "Sketch" does not require accurate plotting — just correct shape, intercepts marked. "Draw" requires accurate plotting using a table of values.
