## Core Rule — Every Transformation Has Required Elements

Cambridge requires **ALL** elements for full marks. A missing element = lost B marks.

| Transformation | Required Elements | Marks |
|---------------|-------------------|-------|
| Reflection | Name + equation of mirror line | B1 + B1 |
| Rotation | Name + angle + direction + centre | B1 + B1 + B1 |
| Translation | Name + column vector | B1 + B1 |
| Enlargement | Name + scale factor + centre | B1 + B1 + B1 |

- B1 for "Reflection"

## 2. Rotation

### What the mark scheme rewards
- "Rotation" [B1]
- Angle and direction [B1] — both needed in one mark; e.g., "90° clockwise" not just "90°"
- Centre [B1] — must give coordinates

### Key examples from 2025 papers

**s25_12 Q12(a):** Full rotation described
- B1 for "Rotation"
- B1 for "90° clockwise"
- B1 for centre "(−2, 1)"
- Full marks = 3

**w25_11 Q8(b):** Draw image of triangle A after rotation 180° about (0, 0)
- B2 for correct image at right position
- B1 for correct size and orientation but wrong position
- Full marks = 2

**w25_12 Q11(b):** Draw image after 90° clockwise rotation about origin
- B2 for correct position
- B1 for correct size and orientation but wrong position
- SC1 for correct anticlockwise rotation about (0, 0) [wrong direction]
- Full marks = 2

## 3. Translation

### What the mark scheme rewards

**w25_12 Q11(a):** Shape A → B. Translation.
- B1 for "Translation"

## 4. Enlargement

### What the mark scheme rewards
- "Enlargement" [B1]
- Scale factor [B1] — including negative scale factors (negative = enlargement + half-turn)
- Centre [B1] — must give coordinates

### Special case — negative scale factor

A negative scale factor means:
- The image is on the opposite side of the centre
- It also involves a 180° rotation
- The size ratio is |scale factor|

### Key examples from 2025 papers

**s25_13 Q19:** Enlargement with negative scale factor
- B1 for "Enlargement"
- B1 for centre (1, 0)
- B1 for scale factor −1/2
- Full marks = 3

## 5. Drawing Transformed Images

### Rotation by 180° about origin: (x, y) → (−x, −y)
### Rotation by 90° clockwise about origin: (x, y) → (y, −x)
### Rotation by 90° anticlockwise about origin: (x, y) → (−y, x)
### Reflection in y = x: (x, y) → (y, x)
### Reflection in y = −x: (x, y) → (−y, −x)
### Reflection in x = a: (x, y) → (2a − x, y)
### Reflection in y = b: (x, y) → (x, 2b − y)

### Marking convention for drawing:
- B2 for correct image in correct position
- B1 for correct size and orientation but wrong position (partial credit)
- SC1 for common alternative error stated explicitly

## 6. Combined/Sequential Transformations

### When this appears
Questions where a shape undergoes two transformations in sequence, or where you must find a single equivalent transformation.

### What the mark scheme rewards
- B marks for each correctly drawn image position
- SC2 for a specific alternative transformation sequence (stated in MS)
- SC1 for a partially correct position
- Full marks = 3 (B2 + B1 structure for combined sequence)

### Key examples from 2024 papers

**s24_21 Q6(a):** Draw triangle after translation.
- Answer: vertices at (5, −2), (7, −2), (5, −6)
- B1 for translation of vector (1, k) or (k, −3) — partial if only one component correct
- Full marks = 2

**s24_21 Q6(b):** Describe the single transformation that maps triangle A to triangle B.
- Answer: Enlargement, scale factor −1/2, centre (0, 1)
- B1 for each of the three elements (name, scale factor with correct sign, centre)
- Full marks = 3

**s24_21 Q6(c):** Draw result of combined transformation (complex multi-step).
- Answer: triangle at (−5, 4), (−3, 4), (−3, 5)
- B2 for triangle at intermediate position (−2, −5), (−2, −3), (−3, −3) seen (correct first transformation)
- B1 for correct size/orientation but wrong final position
- SC2 for triangle Q at (3, −6), (1, −6), (1, −7) [specific alternative]
- SC1 for triangle Q at (3, 2), (1, 2), (1, 1) or at (7, −2), (5, −2), (5, −3)
- Full marks = 3

**w24_11 Q9(a):** Describe the transformation from shape B to shape C.
- Answer: Enlargement, scale factor 3, centre (3, 4)
- B1 for each element
- Full marks = 3

**w24_11 Q9(b):** Draw image of shape B after combined transformation.
- Answer: triangle at (−2, 5), (−2, 3), (−1, 3)
- B1 for translation by (−3, y) or (x, 2) — partial credit for one component correct
- SC1 for translation of shape B by (−3, 2)
- Full marks = 2

**w24_12 Q16(a):** Draw image after translation.
- Answer: vertices at (1, −1), (2, −1), (2, −2), (5, −2), (5, −3), (1, −3)
- B1 for translation by (k, −5) or (3, k) — partial credit for one component correct
- Full marks = 2

**w24_12 Q16(b):** Describe transformation.
- Answer: Rotation, 90° clockwise, centre (4, 1)
- B1 for each element
- Full marks = 3

**s24_22 Q5(a):** Describe transformation from A to B.
- Answer: Reflection, y = −x oe
- B1 for "Reflection"; B1 for "y = −x"
- Full marks = 2

**s24_22 Q5(b)(i):** Find coordinates after enlargement.
- Answer: (−4, 5) [B2; B1 for (−4, k) or (h, 5) with h < −2]
- Full marks = 2

**s24_22 Q5(c)(ii):** Describe transformation.
- Answer: Rotation, 90° anticlockwise, (0, 0)
- B1 for Rotation; B1 for 90° anticlockwise oe; B1 for (0, 0)
- Full marks = 3

## Marking Traps — Transformations Topic

1. **All elements required**: Writing "Rotation, 90°" without the centre or direction = B1 only (out of B3). This is a very common mark loss.
2. **Direction of rotation**: "Clockwise" and "anticlockwise" are different — wrong direction = B0 for that element.
3. **Column vector format**: Must use column vector (top number over bottom number), not bracket notation like (−5, −4) as a coordinate pair.
4. **Negative scale factor**: Must say "scale factor −1/2" not just "scale factor 1/2". Omitting the negative sign = B0 for scale factor. How to identify a negative scale factor: if the image is on the OPPOSITE side of the centre of enlargement from the object, the scale factor is negative. If on the same side, it's positive. (Lesson from s24_21 Q6(b) — the KB had +1/2 but the MS confirmed −1/2 because triangles A and B were on opposite sides of centre (0, 1).)
5. **Centre of enlargement**: Must give the coordinates, not just say "the origin" (unless it is the origin — then "(0, 0)" is the required answer).
6. **"Single transformation"**: If the question says "describe fully the single transformation", writing two transformations (e.g., "reflection and rotation") = B0.
7. **Anticlockwise vs Clockwise SC1**: Some questions specifically award SC1 for the anticlockwise version when clockwise is required — check mark scheme carefully.
