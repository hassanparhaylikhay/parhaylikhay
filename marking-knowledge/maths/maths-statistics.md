## 1. Mean — From a Frequency Table (Grouped Data)

### What the mark scheme rewards
- M1 for finding correct midpoints
- M1 for calculating Σfx (sum of frequency × midpoint)
- M1 dep (dep on 2nd M1) for dividing by Σf (total frequency)
- A1 for correct final answer

### Key examples from 2025 papers

**s25_22 Q18(a):** Mean from frequency table (300 people)
- M1 for midpoints identified correctly
- M1 for Σfx calculated with midpoints in correct interval
- M1 dep for ÷ 300
- Full answer: 52.4
- Full marks = 4 (M3A1)

**w25_21 Q17(a):** Mean from frequency table (80 people completing a race)
- M1 for correct midpoints soi
- M1 for Σfx (x must be in correct interval including boundaries)
- M1 dep (on 2nd M1) for Σfx ÷ 80
- Full answer: 43.875
- Full marks = 4 (M3A1)

**w25_22 Q24(b):** Mean from histogram (frequency density given)
- M1 for correct frequencies: 3.9 × 20 and 4.5 × 20 and 0.9 × 60 soi (frequency = freq density × class width)
- M1 for identifying class midpoints: 180, 210, 230, 270 soi
- M1 for Σf × x where x is in correct interval
- M1 dep for ÷ 250 (total frequency)
- Full answer: 226.8 nfww
- Full marks = 5 (M4A1)

### Critical point about midpoints
- Midpoint of 20 ≤ t < 30 is 25 (not 20, not 30)
- "x is in the correct interval including boundaries" — mark scheme allows midpoints to include boundary values if consistently applied
- Using the wrong value in an interval (e.g., using the lower boundary instead of midpoint) = M0 for Σfx

## 7. Frequency Tables — Completing and Reading

### Key examples from 2025 papers

**w25_22 Q24(a):** A histogram shows height (or similar continuous data). The class 160 ≤ h < 200 has a frequency density of 0.7. Show that the frequency for this class is 28.

- Full marks = 1

## 9. Mean from Table with Unknown Frequencies (Two-Variable Problem)

### When this appears
A frequency table has two unknown frequencies p and q. The total frequency and the mean are both given. This creates a **system of two equations** that must be solved simultaneously.

### What the mark scheme rewards
- B1 for p + q = total − (known frequencies): "p + q + [known totals] = n oe"
- B4/B5 for setting up the mean equation correctly using midpoints × frequencies
- M marks for the mean equation: Σ(f × midpoint) / n = mean
- B1 for correct midpoints identified

### Key examples from 2024 papers

**s24_22 Q9(b):** Frequency table with 50 values, known frequencies 15 and 17, unknown p and q. Mean = 1.81.
- Equation 1: p + q + 15 + 17 = 50 → p + q = 18
- Midpoints: 1.6 (for class containing p), 1.75 (for class 15), 1.85 (for class 17), 2.1 (for class q)
- Equation 2: (1.6p + 1.75×15 + 1.85×17 + 2.1q) / 50 = 1.81
- → 1.6p + 2.1q = 32.8 oe
- Solve simultaneously: p = 10, q = 8
- Full marks = 6 (B5 + B1 structure with multiple intermediate marks)
- B5 for both equations correctly formed; B4 for mean equation alone; B1 for p + q = 18

**s24_21 Q2(b)(i):** Mean from frequency table with midpoints.
- B1 for correct midpoints soi
- M1 for Σ(f × midpoint) / total frequency
- Full answer: 7.88 or 7.884...
- Full marks = 3

**w24_22 Q2(b)(iii):** Estimated mean from grouped frequency table.
- B1 for correct midpoints soi
- M1 for Σ(f × midpoint) / total
- Full answer: 55.9
- Full marks = 3

## Marking Traps — Statistics Topic

1. **Mean with grouped data**: Using boundary values (e.g., 20, 30) instead of midpoints (e.g., 25) = M0 for Σfx step. Always use midpoints.
2. **Median from cumulative frequency**: Must READ from the diagram — calculating directly from the data table misses the point of the diagram question. Award marks only for reading from graph.
3. **Histogram frequencies**: Must multiply frequency density × class width — forgetting this step (using frequency density as frequency) is a very common error.
4. **Mean from weighted groups**: Must use (n₁x̄₁ + n₂x̄₂)/(n₁ + n₂) — not average of the two means.
5. **Pie chart angles**: Must sum to 360°. If one is wrong and student gets wrong total, they lose marks.
6. **Bar chart**: "Linear scale starting from 0" is a separate B mark — even if bars are correct, this B mark is lost if scale is wrong.
7. **Scatter graph line of best fit**: Must be a RULED straight line passing through the point cloud, not connecting dots or passing through origin necessarily.
