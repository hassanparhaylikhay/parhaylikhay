## 1. Right-Angled Trigonometry (SOH-CAH-TOA)

### What the mark scheme rewards
- Correct identification of the sides relative to the angle (opp, adj, hyp)
- Correct trig ratio set up (M1)
- Correct answer with appropriate units (A1)

## 2. Sine Rule

### Formula: a/sinA = b/sinB = c/sinC

### What the mark scheme rewards
- M1 for correctly setting up the sine rule with correct sides/angles
- M1dep for correct calculation
- A1 for correct answer (often awrt a value)

### Key examples from 2025 papers

**s25_23 Q19(b):** In triangle ABC, angle BAD = 24.5° (from part a). Angle BAC = 100°. One side is known. Find AC using the sine rule.
- Angle ABC = 100 − 24.5 = 75.5°
- M1 for angle ABC = (100 − 24.5) [deriving the angle from part a]
- M2 for AC/sin(ABC) = [known side]/sin(known angle)
- M1 for setting up sine rule correctly
- Full answer: AC = 15.6 cm
- Full marks = 4 (combined with Q19a)

**w25_22 Q20(b):** Triangle with sides 65, 75, and 124.3 cm (124.3 from part a). Find angle B, opposite the 75 cm side.
- M2 for sin B = 75 sin125° / 124.3 oe
- Alternative: [cos B =] (65² + 124.3² − 75²) / (2 × 65 × 124.3) oe (cosine rule)
- Full answer: 29.6° or 29.59° to 29.64°
- Full marks = 3

**w25_21 Q20(b):** Same triangle as w25_22 Q20 — sides 65 cm and 75 cm with angle 125° between them (from part a, third side = 124.3 cm). Find the angle opposite the 75 cm side.
- M2 for sin B = 75 sin125° / 124.3 oe
- M1 for 75/sinB = 124.3/sin125° oe (sine rule set up)
- Full answer: 29.6° or 29.59° to 29.64°
- Full marks = 3

## 3. Cosine Rule

### Formula: a² = b² + c² − 2bc cosA (to find side) OR cosA = (b² + c² − a²)/(2bc) (to find angle)

### What the mark scheme rewards
- M1 for writing the cosine rule correctly with all values substituted
- A1 for correct answer

### Key examples from 2025 papers

**s25_22 Q22(a):** Triangle with two known sides 65 m and 75 m, and the included angle = 125°. Find the third side.
- M2 for full cosine rule substitution: a² = 65² + 75² − 2×65×75×cos125°
- M1 for 65² + 75² − 2×65×75×cos125° (partial substitution)
- Full answer: 124.26 to 124.27
- Full marks = 3 (M2A1)

**w25_22 Q22(b):** Triangle with all three sides known: 620 m, 495 m, 580 m. Find the angle opposite the 580 m side.
- M2 for [cos θ =] (620² + 495² − 580²) / (2 × 620 × 495) oe
- M1 for 580² = 620² + 495² − 2×620×495×cos θ oe (writing cosine rule before rearranging)
- Full answer: 61.48...°
- Full marks = 3 (M2A1)

**s25_23 Q19(a):** Quadrilateral ABCD. Diagonal BD = 144 and AD = 131 are known. Find angle BAD = 24.5° using the cosine rule.
- B3 for cos(BAD) = 131/144 oe (full cosine rule fraction correctly formed)
- M2 for cosine rule set up fully with correct sides
- M1 for identifying the correct triangle and substituting any two sides
- Full answer: 24.5°
- Full marks = 4 (B3 + one more mark for correct setup)

**w25_21 Q20(a):** Triangle with two sides 65 cm and 75 cm, included angle 125°. Find the third side using the cosine rule.
- a² = 65² + 75² − 2×65×75×cos125°
- M2 for correct full cosine rule substitution
- M1 for partial substitution (missing one term or wrong sign)
- Full answer: 124.26 to 124.27
- Full marks = 3

## 4. Area of Triangle = ½ab sinC

### Key examples from 2025 papers

**s25_22 Q22(b):** The triangle from Q22(a) (sides 65, 75, 124.3 m; angle 125°) represents a piece of land. Find its area.
- Area = ½ × 65 × 75 × sin125°
- M3 for area formula correctly applied with the found values
- Full answer: 92.8 to 92.9 m²

**w25_21 Q20(c):** In the triangle from Q20(a) (sides 65, 75, 124.3 cm; angle 125° between the 65 and 75 sides), find the shortest distance from the vertex opposite the 124.3 side to the 124.3 cm side (i.e., the perpendicular height from that vertex to BC).

## 3b. Cosine Rule → Quadratic → Sine Rule Chain

### When this appears
A triangle question where: one side is unknown (variable x), the cosine rule produces a quadratic in x, you solve it, then use the sine rule to find an angle.

### What the mark scheme rewards
- M2 for correct cosine rule substitution (including cos of given angle)
- M2 for correct quadratic formula applied to the quadratic
- A1 for correct roots (taking the positive one)
- M1 for correct sine rule to find angle
- B1 for correct final answer nfww

### Key example from 2024

**s24_22 Q10(b):** Triangle with sides 8 and 15, angle = 120° between them. Find ED.
- Cosine rule: 15² = 8² + x² − 2(8)(x)cos120° → x² + 8x − 161 = 0
- M2 for 15² = 8² + x² − 2(8)(x)cos120° oe [M1 for partial substitution]
- Solve quadratic: x = (−8 ± √(64 + 644)) / 2 → x ≈ 11.3 (take positive root) — wait: the question asks for ED using sine rule after solving, the answer is 9.3
- M2 for quadratic formula applied; M1 for discriminant (8² + 4×161) oe
- Sine rule for ED: sin(ADE)/15 = sin120°/their x → ED
- Full answer: 9.3 nfww
- Full marks = 8 total (multiple M marks and B1 for final answer)

## 7. Pythagoras' Theorem

### Key examples from 2025 papers

**w25_11 Q17(a):** Height of isosceles triangle (sides 13, base 10)
- h² = 13² − 5² = 169 − 25 = 144 → h = 12
- M1 for h² + 5² = 13² oe

**w25_12 Q23:** AB = 12√2 cao
- B3 for MX = √72 oe or AB = 2√72 oe
- M2 for MX² = 11² − 7² = 72
- M1 for x² + 72 = 11²

**w25_22 Q10(b):** Find |a + b| where a = (−3, 4) and b = (8, −2) are column vectors
- a + b = (−3 + 8, 4 + (−2)) = (5, 2)
- |a + b| = √(5² + 2²) = √(25 + 4) = √29 ≈ 5.385
- M2 for (−3 + 8)² + (4 + (−2))² oe correctly set up
- M1 for (−3 + 8) and (4 + (−2)) correctly found soi
- Full answer: 5.39 or 5.385... (3 sf)
- Full marks = 3

Note: This is a vectors question (finding magnitude of a + b), not a distance between coordinate points.

## Marking Traps — Trigonometry Topic

1. **Cosine rule**: Don't confuse which formula to use — for FINDING A SIDE use a² = b² + c² − 2bc cosA; for FINDING AN ANGLE rearrange to cosA = (...)/(...). M1 requires correct formula direction.
2. **Sine rule ambiguous case**: At O-Level, usually the acute answer is expected unless context demands otherwise.
3. **Angle finding**: must show the cos/sin/tan equation before using inverse trig — M1 is awarded for the equation, A1 for the value.
4. **3D Pythagoras**: must find the correct base diagonal first — this is M1 in the marking scheme.
5. **Calculator use**: Paper 2 questions — intermediate values must be kept on the calculator. Rounding intermediate to 1 d.p. and then using that rounded value can cost the accuracy mark (premature rounding).
6. **Area formula**: ½ab sinC requires the INCLUDED angle between sides a and b. Wrong angle = wrong formula = M0.
7. **Bearings with right-angle trig**: Which side is adjacent and which is opposite depends entirely on the diagram — the bearing angle and the labelled sides determine the ratio. When a bearing entry in this KB says "cos42° = AB/495", that means AB is the adjacent side to the 42° angle. If the diagram were different, the same numbers could give a different trig ratio. Always reconstruct the right-angled triangle from the diagram before applying SOH-CAH-TOA.
8. **Diagram-reconstructed entries**: Some entries in this file (and others) were written without access to the original QP diagram. Where an entry says "*Note: verify against QP*", treat the specific trig ratio and which side is which as approximate — the marking pattern and method marks are reliable, the exact ratio may need adjusting.
